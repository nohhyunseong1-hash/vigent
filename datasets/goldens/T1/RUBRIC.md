# T1 rubric 채점표 + 치명적 오류 체크리스트

> **확정값(강사 확정, 2026-07-24 반영).** 케이스별 정답·점수는 여전히 강사 채점 대상.
> 합격 = **총점 ≥ 80/100 AND 치명적 오류 0건**. (둘 중 하나라도 미충족이면 불합격)

## A. rubric 배점 (100점) — 확정값
전문가(강사)가 케이스별로 각 항목에 점수를 부여한다. 각 항목은 0~배점 사이.

| 항목 | 배점 | 채점 관점(제안) |
|---|---|---|
| 1. 위험요인 식별 완전성 | **30** | 해당 공정의 핵심 위험요인을 빠짐없이 식별했는가(누락=감점). 비전 사각지대·문서항목도 "수동확인"으로 표면화했는가. |
| 2. 위험성 추정(가능성×중대성 등급) 적절성 | **25** | 빈도·강도·등급이 현장 실태에 맞는가. 과대·과소평가 없는가. |
| 3. 위험성 감소대책 실효성·구체성 | **25** | 대책이 실제로 위험을 낮추는가. 고시12조 위계(제거·대체>공학적>관리적>보호구) 순서·구체성. |
| 4. 법적 근거·형식 정확성 | **10** | 인용 법령이 실재·적합한가. KOSHA 서식·컬럼 형식 정확성. |
| 5. 우선순위·잔류위험 관리 | **10** | 위험 높은 항목 우선 배치, 잔류위험 명시·후속조치 지정. |
| **합계** | **100** | |

**합격선(제안): ≥ 80/100.**

## B. 치명적 오류 체크리스트 — 제안값
아래 중 **하나라도 해당(true)이면 rubric 점수와 무관하게 자동 불합격**.
케이스별로 강사가 O(해당=오류있음)/X(해당없음)로 표시.

| # | 치명적 오류(제안 정의) | 판정 |
|---|---|---|
| C1 | **중대재해 직결 핵심 위험요인 누락** (사망·중상 직결 위험을 빠뜨림) | ☐ |
| C2 | **실재하지 않는 설비·공정·물질 언급**(환각) | ☐ |
| C3 | **법령·기준 오인용 또는 존재하지 않는 조문 인용** | ☐ |
| C4 | **위험성 등급 2단계 이상 과소평가**(예: 상→하) | ☐ |

> C2·C3은 자동 보조검증 가능: C3 조문 실재성은 화이트리스트(`statutes.yaml`)로,
> C2 환각 설비/물질은 케이스 원본 대비 대조로 1차 스크리닝(최종 판정은 강사).

## C. 자동 채점기와의 관계(참고)
기존 `scripts/golden_score_checklist.py`는 **구성요소 개수**(커버리지·위험수준 일치·위계·법령재현·환각·O오탐)를
결정적으로 낸다. 이는 위 rubric의 **보조 근거**로 쓰되, **A등급 판정의 본체는 위 전문가 rubric(강사 채점)**이다.
(자동 지표를 rubric 점수로 자동 환산하지 않는다 — 환산식 채택 여부도 강사 확정 사항.)
