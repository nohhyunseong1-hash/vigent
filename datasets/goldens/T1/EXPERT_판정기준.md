# T1 판정기준 (전문가 확정 · 2026-07-24)

> 강사(산업안전 전문가) 확정. 나머지 14+1케이스 채점의 일관성 기준.

| 기준 | 확정 | 세부 |
|---|---|---|
| **1. C1(핵심위험 누락)** | O | '핵심위험'은 각 케이스의 **최상위 사망위험**(추락·끼임·질식·감전·화재폭발·붕괴/매몰)으로 한정. 유사항목으로 대체 기술돼 있으면 누락 아님. |
| **2. 부분점수(3단계)** | O(수정) | 항목 채점: **적정성 정답 일치 = 배점 100% · 위험수준만 오답 = 배점 50% · 적정성 오답 = 0%**. |
| **3. 비전 사각지대** | O | 제품이 '수동확인'으로 표시했으면 감점 안 함. **단 생명직결 필수통제**(산소농도 측정·정전검전·인화물 제거 등)를 '수동확인'으로만 넘기면 **C1(핵심위험 누락)으로 별도 감점**. |

## C 정답표 판정 원칙(강사 명시)
- 15케이스는 모두 "위험 실재 상황"으로 설계 → 나열 점검항목은 전부 **관리 필요한 실제 위험요인** → 정답 적정성 원칙적으로 **X(부적정=조치 필요)**. 제품 출력에서 통제가 실제 이행 확인되면 그 항목만 O.
- 제품이 '수동확인(−)'으로 남긴 항목도 전문가 정답은 **실제 위험수준을 부여**(비전 사각지대라도 위험 자체는 존재).
- 법령: 모두 「산업안전보건기준에 관한 규칙」(안전보건규칙) 조문. 최근 개정 2025.7.17.(고용노동부령 제448호) — 최종본은 국가법령정보센터 대조 권장.
- 감소대책: 위험성 감소조치 우선순위(제거·대체 → 공학적 → 관리적 → 보호구) 순 적용.
