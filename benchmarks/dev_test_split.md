# [P-0] dev/test 분할 확정 (2026-08-10, 사용자 승인 완료 — 이후 변경 금지)

> **원칙(어기면 안 됨)**: 이 시점부터 모든 A/B·튜닝 실험은 **dev로만 채점**한다. **test는 전 실험
> 종료 후 단 1회만** 연다. 자세한 원칙은 `docs/perf_improvement_plan.md` 최상단 참고.

## 방법 — 영상(비디오) 단위 분할, 프레임 무작위 분할 아님

109장은 9개 원본 영상에서 1000ms 간격으로 뽑은 것이라, 같은 영상의 인접 프레임은 배경·조명·인물이
거의 동일한 **근접중복**이다. 프레임 단위로 무작위 분할하면 dev/test에 닮은꼴 프레임이 함께 들어가
test 성능이 실제보다 부풀려진다(누출). 그래서 **9개 영상 자체를 dev/test에 통째로 배정**한다.

## ★불가피한 한계 (9개 영상뿐이라 구조적으로 못 고침, 규칙7)

- **Hardhat·Safety-Vest는 test에서 사실상 평가 불가**(Hardhat 1건, Vest 0건) — 두 클래스가 특정
  1~2개 영상(438282·611749)에 몰려있고 그 영상들이 전부 dev 쪽이라 생기는 결과. Safety-Vest는
  전체 2건뿐이라 애초에 어느 쪽에 있어도 측정 불가(`field_eval_gt_summary.md` §4 결론 유지).
- **Mask는 반대로 test에 100% 쏠린다**(dev 0건, 632301 영상이 유일한 출처). Mask는 현재 실험
  우선순위(P-1~P-3)에 없어 영향은 작지만, dev 반복 실험 중에는 Mask 상태를 확인할 수 없다.
- 근본 해결책은 새 영상 확보뿐 — `docs/perf_improvement_plan.md` 5순위(정답지 신뢰도 보강)와
  동일한 결론.
