# B8 — 쓰러진/저자세 사람 검출 측정 자산 (회귀·재현용)

> rig_monitor (b) 낙상 obs 신뢰성 조사(B8, 2026-07-17)의 측정 스크립트·결과 보존.
> 결론·재개조건은 [../../docs/P3_BACKLOG.md](../../docs/P3_BACKLOG.md) B8 참조.
> 검증 영상 `footage/크레인재해.MP4`(1280x720 24fps 45.5s HEVC)는 대용량이라 gitignore(로컬 관리).
> 주석 obs `footage/크레인재해.obs.csv`도 로컬. 이 스크립트들은 그 영상 프레임을 디스크로 추출해 돌린 것.

## 결과 요약 (크레인재해 영상, n=1)
| 측정 | 결과 |
|---|---|
| baseline recall(기본 임계 0.4) | 쓰러진 작업자 **0%** |
| 저임계(a) | thr0.05 **80%**, thr0.02 **90%** (검출 conf 0.05~0.24) |
| 타일링(e) | recall **95%**, conf 0.24→**0.56**, 시간 **3.8×** |
| YOLO11m(f) | **0%** (RF-DETR≫YOLO) |
| 자세/pose 확정(c) | pose 산출 **3.9%**, '쓰러짐' 플래그 **0** → 불가 |
| bbox 종횡비(b) | 사고 median 0.79 vs 무사고 1.5 → 분리 안 됨 |
| 시간단서(정적-지속) | 쓰러진자 8s 정적 → T5s recall 1/1·오탐 3/35s (어드바이저 경계선) |

**결론**: 검출 recall 은 구역-타일링으로 해결(→ B9). **자동 '낙상' 특정은 이 해상도(26~64px)로 불가.**

## 스크립트 (재현 시 프레임 경로만 조정)
- `b8_lowthr.py` — 저임계(0.05/0.02) ROI recall.
- `b8_measure3.py` — ① 저임계 오탐 ② 타일링(recall·conf·시간배수) ③ YOLO11m A/B.
- `b8_confirm.py` — 구역-타일 검출 + (b)종횡비 + (c)RTMPose 자세지표(산출률 포함).
- `b8_temporal.py` — 2fps 트래킹 + 정적-지속 스윕(T=3/5/10s).
- `*.result.json` — 각 측정의 실제 출력(근거 보존).

## 재현 방법(개요)
1. `footage/크레인재해.MP4` 배치.
2. cv2 로 사고구간(t36~45)·무사고(t0~35) 프레임을 stride 로 JPG 추출(스크립트 상단 경로 참조).
3. `VIGENT_ALLOW_FALLBACK=1 python b8_*.py` (RF-DETR COCO 폴백 사용). 모델로드 ~251s(느림) → 백그라운드 권장.

## 재개 조건(요약)
- 어드바이저 검증: 낙상 사고 영상 ≥10건 + 정상 리깅 ≥3시간 (n=1 탈피).
- 근접 카메라: rig 구역 작업자 **≥120px**(현재 61px median) — pose 안정 하한. 상세는 P3_BACKLOG B8.
