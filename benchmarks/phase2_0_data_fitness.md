# Phase 2-0 — 라벨링 전 데이터 적합성 점검 (측정 전 눈대중 확인, 라벨링 미시작)

> 방법: 자동 PPE 분류기가 없어(이 조사의 목적 자체가 그 정확도를 재려는 것이므로 순환논리 회피),
> person 포함 96장 전부를 6장짜리 4×4 몽타주(`data/field_eval/montages/ppe_batch_00~05.jpg`)로
> 만들어 육안으로 직접 확인·집계했다. 자동 추정이 아니라 실제로 하나씩 본 결과다(규칙7).

## 1) PPE 착용 분포 (person 96장)

| 항목 | 착용(O) | 미착용(X) | 판별불가(원거리·부분샷·각도) |
|---|---|---|---|
| **안전모(Hardhat)** | 30장 (31%) | 49장 (51%) | 17장 (18%) |
| **안전조끼(Safety-Vest)** | **0장 (0%)** | 73장 (76%) | 23장 (24%) |

**중요 발견(규칙7 — 있는 그대로 보고)**: 96장 전체에서 고시인성(hi-vis) 안전조끼를 착용한 사람이
**단 한 명도 없었다.** 안전모를 쓴 작업자(철근 작업조·고소 로프작업자)도 조끼는 안 입었다(패딩·점퍼
차림). → **Safety-Vest(착용) 클래스의 양성(positive) 샘플이 이 109장에 0개**라는 뜻 — NO-Safety-Vest
recall 은 측정 가능하지만, **Safety-Vest 오탐률(정상 착용을 미착용으로 잘못 판정하는 비율)은 이
데이터로 측정 불가**(비교할 착용 샘플 자체가 없음). Hardhat 은 착용/미착용 둘 다 표본이 있어(30/49)
양방향 측정이 가능하다.

## 2) 원거리 22장 — PPE 판별 가능 크기인가

사용자 기준 "화면의 1/10 이하"를 person 박스 **높이/프레임 높이** 비율로 적용하면(`height_frac`,
`frames_manifest.json` 실측치) **0/22 장이 0.10 미만**(최소값 0.11) — 문자 그대로의 1/10 기준으로는
전부 통과한다.

**단 육안으로 직접 22장을 다시 확인한 결과(`montages/far_sorted.jpg`, height_frac 오름차순 정렬)**,
0.10 기준은 실제 판별가능성과 안 맞았다:
- **height_frac < 0.15 (5장)**: 로프작업자 최초 등장(0.11~0.13, 3장) + 지게차 사고 초반(0.147~0.149,
  2장) — 인물이 배경 대비 극소·저대비·역광이라 **안전모 색상조차 육안으로 특정 불가**.
- **0.15~0.17 (5장)**: 경계선 — 확대하면 판별 가능할 수도 있으나 확신 낮음.
- **0.195~0.249 (12장)**: 크기는 작아도 로프작업자 안전모 색(주황/빨강)·자세는 식별 가능(뒤 배치
  스크린샷에서 실제로 확인됨).

**권장**: 사용자 제시 기준(1/10=0.10)을 그대로 쓰면 제외 대상이 0장이 되어 실효가 없다. 대신
**height_frac < 0.15(5장)를 "PPE 측정 제외, person 검출만" 으로 분류**할 것을 제안한다(직접 확인
근거 있음). 나머지 17장은 라벨링 시 확대해서 판단하되, 애매하면 "불확실" 값을 쓸 수 있게 라벨
템플릿에 넣는다(Phase 2에서 반영 예정).

## 3) 결측 조건

- **야간(어두운 장면) 0장.** 9개 영상이 전부 주간 또는 조명이 밝은 실내였다(밝기 임계 자체는
  역광후보 17장을 정상적으로 잡아냈으므로 임계값 오류로 보이지 않는다 — 실제로 야간 장면이 없었던
  것으로 판단).
- **결론 — 측정 결과에 붙일 꼬리표**: 이번 109장 기반 정확도 측정은 **"주간·조명양호 기준 —
  야간 미검증"**이다. 야간 성능은 이 데이터셋으로는 어떤 결론도 낼 수 없다(모른다 — 추측 금지).
