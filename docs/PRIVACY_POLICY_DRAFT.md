# VIGENT 개인정보·영상정보 처리방침 (초안 — safety 테마)

> ⚠️ **초안이며 법률 자문이 아니다(규칙7).** 실제 파일럿·상용 전에 **개인정보 전문 법무 검토**를 받아야 한다.
> 이 문서는 (1) 현재 코드가 실제로 무엇을 수집·저장하는지, (2) 파일럿 전/중 필요한 정책·기술 통제,
> (3) 아직 **미구현**인 항목을 정직하게 구분해 정리한 것이다.

관련 문서: [TLS_DEPLOYMENT.md](TLS_DEPLOYMENT.md)(전송 암호화) · [CLAUDE.md](../CLAUDE.md)(안전·개인정보 경계) ·
[COMMERCIALIZATION_READINESS.md](COMMERCIALIZATION_READINESS.md) §2 블로커 9.

## 1. 적용 범위·성격
- 대상: **safety 테마** — 산업현장 CCTV 영상에서 위험(위험구역 침입·보호구 미착용·프레스 부위별 경보·화재/연기·부담자세·협착 근접) 탐지.
- 성격: **보조·감시 계층**. 비전 ML 은 확률적이며 **인증 안전기능(Type 4 방호장치·안전 PLC)을 대체하지 않는다.**
- office 테마는 설계상 **익명**(이름·얼굴 없이 브라우저 랜덤 토큰으로만 집계) — 본 방침의 식별정보 이슈는 주로 safety 현장영상.

## 2. 법적 근거·경계 (검토 대상)
- **개인정보보호법**: 영상정보처리기기 운영(§25) — 설치 목적·장소 **안내판** 의무, 목적 외 이용·임의조작 금지.
- **근로기준법·취업규칙**: 근로자 감시에 해당할 수 있어 **취업규칙 반영·근로자 고지** 필요.
- **근로자참여법(노사협의회법)**: 사업장 내 감시설비 설치는 **노사협의 대상**.
- **중대재해처벌법**: VIGENT 는 **보조 신호**일 뿐 법적 안전조치를 대체하지 않음(계약서 명문화 필요).
- (클라우드 VLM 사용 시) **국외이전·처리위탁** 고지·동의(아래 §7).

## 3. 실제 수집·저장 항목 (현재 코드 기준)
| 항목 | 저장 위치 | 내용 | 식별성 |
|---|---|---|---|
| 위험 이벤트 증거프레임 | `data/evidence/<날짜>/ev_*.jpg` | 위험 감지 순간 **원본 프레임(얼굴 포함 가능)** | **높음(비식별화 미적용)** |
| 인식 로그 | `data/recognition/events_*.jsonl` | rule·level·score·site·시각·note | 낮음(영상 아님, 단 site+시각 결합 시 특정 가능) |
| 카메라 스트림 | (실시간, 미저장 원칙) | RTSP 프레임 처리 | — |
| recognition(출입) | 별도 | 얼굴인식 — **현재 실동작·정확도 미검증** | (미검증) |
- 증거프레임은 **로컬에만** 저장한다([data_engine.py](../vigent-core/data_engine.py) §8.3).

## 4. 처리 목적·목적 외 금지
- 목적: 위험 탐지·경보·안전서류(위험성평가서·TBM) 자동화. **근태·인사평가 등 목적 외 이용 금지.**

## 5. 보관기간·파기 (정책 설정 필요)
- **권고**: 증거프레임·로그 보관기간을 파일럿 정책으로 **명시(예: 30일)** 하고 경과 시 자동 파기.
- **현재 상태**: 자동 보관기간 삭제 **미구현** → 파일럿 전/중 구현 권고(아래 §9 후속).

## 6. 얼굴 비식별화 (미구현 — 핵심 후속)
- **현재**: safety 증거프레임은 **얼굴 블러/마스킹 미적용**(원본 저장). data_engine 주석이 "비식별화·암호화는 상용 단계 과제"로 명시.
- **권고**: 작업자 **식별이 불필요한 목적**(위험 탐지)에는 저장 시 **얼굴 블러 기본 on**. 식별이 필요한 예외만 별도 근거·동의.

## 7. 클라우드 전송(위탁·국외이전) — opt-in
- 기본은 **로컬 VLM**(프레임 외부 전송 없음).
- **클라우드 VLM(OpenAI/Anthropic)** 은 **opt-in(F-12)** — 키만으로 무동의 전송을 막는 게이트가 있음. 활성 시 **프레임이 국외 서버로 전송**되므로: 정보주체 동의, **처리위탁·국외이전 고지**, 위탁계약(재위탁·파기) 필요.

## 8. 접근통제·보안
- 인증: `VIGENT_API_TOKEN`(상수시간 비교) · 강제 옵션 `VIGENT_REQUIRE_TOKEN=1` · Host 허용목록(DNS-rebinding 방어).
- 전송: TLS([TLS_DEPLOYMENT.md](TLS_DEPLOYMENT.md)).
- 저장: 로컬, path traversal 차단(P0-1). **저장 암호화는 미구현**(§9 후속).
- 최소권한: 증거 디렉토리 접근 제한.

## 9. 미구현·후속 항목 (정직 — 파일럿 전/중 구현/검토 대상)
1. **얼굴 비식별화(블러)** — safety 증거프레임 저장 시 자동 블러. (미구현)
2. **보관기간 자동 파기** — N일 경과 증거·로그 자동 삭제 배치. (미구현)
3. **저장 암호화** — 증거프레임 at-rest 암호화. (미구현)
4. **정보주체 권리 절차** — 열람·삭제·처리정지 요청 접수·처리 흐름. (문서·운영 절차 필요)
5. **안내판·고지문·동의서·노사협의록** 양식. (문서 필요 — 법무)
6. **recognition 얼굴인식** 정확도·목적 정당성. (미검증)

## 10. 고지·동의·노사협의 (운영 준비물)
- [ ] 영상정보처리기기 **안내판**(목적·장소·관리책임자·연락처) 설치.
- [ ] 근로자 **고지문**(수집 항목·목적·보관기간·권리) 배포.
- [ ] **노사협의** 진행·기록(감시 목적·범위·비식별화 방침).
- [ ] (클라우드 VLM 사용 시) **동의서 + 국외이전·위탁 고지**.
- [ ] 파일럿 계약서에 **"인증 안전기능 대체 아님·오탐/미탐 면책·데이터 소유·파기"** 명문화.
