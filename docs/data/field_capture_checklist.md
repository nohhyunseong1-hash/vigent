## 3. 30분 단위 조합표 (주간 1h = 2세션 · 야간 1h = 2세션, 카메라 4곳 동시 녹화)

각 세션 30분 안에 아래 조합을 **모두** 한 번 이상. 조합당 2~3분, 근/원거리를 바꿔 가며.

| 안전모 | 조끼 | 동작(각 조합마다 4가지 다) | 거리 |
|---|---|---|---|
| 착용 | 착용 | 서기 · 걷기 · 굽히기 · 지게차 옆 | 근(5~10 m) + 원(20~30 m) |
| 착용 | 미착용 | 서기 · 걷기 · 굽히기 · 지게차 옆 | 근 + 원 |
| 미착용 | 착용 | 서기 · 걷기 · 굽히기 · 지게차 옆 | 근 + 원 |
| 미착용 | 미착용 | 서기 · 걷기 · 굽히기 · 지게차 옆 | 근 + 원 |

- 세션 A(주간 1): 조합표 1회 · 세션 B(주간 2): 조합표 + 겹침(2~3명 붙어 서기)·부분 가림(기둥·지게차 뒤) · 세션 C(야간 1): 조합표(조명 켠 상태) · 세션 D(야간 2): 조합표(조명 일부 끔, 역광 카메라 포함)
- 각 세션 시작·끝에 **아무도 없는 30초**(음성 프레임용)와 **지게차만 지나가는 30초**를 넣는다.
- 세션마다 스마트폰으로 현장 전경 1장 + 세션 시작 시각 메모(카메라 ID·주야·인원·조합 진행 여부).
