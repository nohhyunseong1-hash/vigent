## 4. 제외·주의 사항 요약

1. **Mask/NO-Mask**: 두 데이터셋 모두 해당 클래스가 없고, 있더라도 제외한다(원칙).
2. **Hardhat 파생은 조건부**: 시나리오 폴더 `WO-01` 이 "위반 없음"이라는 가정은 라벨 규칙이 아니라 촬영 통제에 기댄 [추정](A-1 §3). 육안 판정 값이 오기 전에는 생성하지 않는다.
3. **507 조끼 없음**: `Safety-Vest`/`NO-Safety-Vest` 는 507·510 어느 쪽에서도 보강되지 않는다.
4. **스케일**: 두 데이터셋 모두 사람 중앙 347~423 px(근접 촬영) — 현장 26~64 px 과 다르다. 축소 증강은 옵션이며 효과는 미검증.
5. **누출**: 507 은 장소ID 단위, 510 은 영상 단위로 나눈다. `공통`(미착용) 과 시나리오 폴더가 장소를 전부 공유하므로(A-1 §6-2) 장소ID 로 나누면 미착용/착용이 같은 장소에서 한쪽 분할에만 들어간다 — 장면 지름길 학습을 억제하는 방향.
