# 02. 읽는 순서 — 위험이 큰 곳부터

> **이 문서로 판단할 수 있는 것**: 어떤 순서로, 어떤 질문을 들고 읽을지.
> **판단 못 하는 것**: 코드의 옳고 그름 — 그건 원문을 읽는 사람 몫이다.
> ★소요 시간은 전부 **추정**이다(코드 줄수 ÷ 통상 정독 속도. 재 본 값 아님).

경로는 데이터 흐름을 따른다:
**카메라 → 캡처 → 검출 → 추적 → 파생 → 규칙 → 게이트 → 큐 → 텔레그램**

지목한 우선순위 그대로가 맞다고 본다 — 근거: 1순위(경보 사슬)는 **죽으면 아무도 경고를
못 받는데 합계 816줄로 가장 짧아** 투자 대비 효과가 최대다. 판정 경로는 길지만(1,014줄+)
틀려도 "잘못 울리는" 쪽이 많고, 경보 사슬이 죽으면 "아예 안 울린다".
