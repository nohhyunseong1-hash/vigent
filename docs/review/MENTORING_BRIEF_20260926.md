## 3. 멘토가 물을 법한 질문 10 (§8, 요지)

1. **왜 YOLO 안 쓰나** — AGPL. RF-DETR(Apache-2.0)로 이관, person raw mAP 90.82→93.92(공개셋)라 손해 없음. 지게차만 학원 프로파일에서 AGPL YOLO 예외(대표 결정 대기).
2. **42% 는 뭐였나** — 사고영상 1fps 추적 후 재현율. 검출 직전 71.3%. 현장 1.88fps 에선 손실 11.7% → 1fps 착시로 확인, **2026-09-22 폐기**. 재방문 정답지로 재측정.
3. **LLM 이 왜 필요한가·L2 는 어디 있나** — 실시간 경보에는 미개입. L1 안에선 문서 서술 문단에만 opt-in. 별도 L2 두 계보는 L1 미연결(§3).
4. **경보 3주 누락 재발 방지** — 기동 시 `getMe` 자가시험·붉은 배너·하루 1회 heartbeat(설정 시)·데드레터 보관·이메일 채널 코드. 미완: heartbeat 기본 꺼짐, 이메일 비밀번호 대기, health 전이 통보 0건.
5. **학습 데이터 권리** — CSS v27 CC BY 4.0(표시 완료), LOCO CC0, COCO 체크포인트 Apache-2.0. **D-Fire 라이선스 미확인.** 현장 원본 학습 데이터 0장. 얼굴 이미지가 git 이력에 잔존(공개 전 재작성 필요).
6. **5060 으로 4채널 되나** — 모른다. 5070 Ti 실측(18.6%·604MB)만 있고 5060 은 sm_120 이라 cu130 빌드 필요까지 확인. 배수 추정 안 함.
7. **현장에서 사람을 몇 % 잡나** — 측정된 적 없다(정답지 없음). 있는 것은 사고영상 검출 71.3%(1fps)와 현장 생존율 88.3%(GT 없음).
8. **미착용을 얼마나 놓치나** — held-out NO-Hardhat 64.1% [51.8, 74.7](2026-09-25), 사고영상 dev [25.9, 100](n=14). 재학습 목표 ≥85%.
9. **넘어지면 잡나** — 아니다. 낙상 감지는 2026-08-06 제거, `immobility` 는 45초 정지만. 대외 문구 "쓰러짐"은 2026-09-26 에 정정.
10. **오탐은 어떻게 막고 얼마나 나오나** — 연속 프레임·시간 디바운스·쿨다운·적응형 백오프(억제 89.1%, 현장 270→19건). 오탐률 자체는 현장 정답지가 없어 못 잰다. 알려진 오탐원: 야간 정지 물체(무인 86.4%), 마스크 단독, 운전자 오인 7.6%.
