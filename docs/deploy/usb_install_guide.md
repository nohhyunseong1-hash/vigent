# VIGENT USB 설치 안내 (현장 담당자용, 1차)

> **대상**: 현장에서 USB 하나로 VIGENT 를 설치하는 사람. 명령어를 몰라도 되게 썼습니다.
> **버전**: USB 루트의 `VERSION.txt` 를 보세요. 설계는 [usb_installer_design.md](usb_installer_design.md).

## 0. 준비물

| 항목 | 확인 |
|---|---|
| PC | Windows 10/11 64bit · NVIDIA GPU(**VRAM 8GB 이상**) · RAM 16GB 이상 · 디스크 여유 20GB 이상 |
| NVIDIA 드라이버 | **버전 580 이상**. 없거나 낮으면 USB 의 `driver\` 폴더 안내대로 먼저 설치하고 **재부팅** |
| 카메라 | RTSP 주소·계정·비밀번호 (예: `rtsp://user:pass@192.168.x.x:554/stream1`) — 카메라 수만큼 |
| 텔레그램 | 봇 토큰 · chat_id (설치 중 입력, USB 에는 저장되지 않음) |
| 이메일(선택) | SMTP 호스트·포트·계정·비밀번호·수신 주소 — 없으면 건너뛸 수 있지만 **채널이 하나뿐이면 그것이 죽는 순간 경보가 아무에게도 가지 않습니다** |
| 인터넷 | **필요 없음**(설치·CUDA 교체 전부 오프라인). 텔레그램 확인(getMe)만 잠깐 인터넷을 씁니다 |

## 1. 설치

1. USB 를 꽂고 루트의 **`설치.bat`** 을 마우스 오른쪽 → **관리자 권한으로 실행**.
2. 자동으로 진행됩니다 — 사양 검사(8항목) → `C:\VIGENT` 복사 → CUDA 교체 → 서비스 등록.
   - 사양 미달이면 **미달 항목이 한 줄씩 전부** 나오고 멈춥니다. 고치고 다시 실행하세요.
   - 이미 설치돼 있으면 **업데이트**로 동작합니다: 데이터·설정·비밀은 그대로, 코드만 바뀌고 이전 버전은 `C:\VIGENT_prev_<버전>` 에 1세대 보관됩니다.
3. 이어서 **첫 실행 마법사**가 뜹니다(첫 설치일 때). 물어보는 대로 입력하세요. **각 입력 직후 검증**하므로 틀리면 그 자리에서 다시 묻습니다.
   1) 기기명 → 2) 프로파일(`academy` 기본) → 3) 카메라(주소 입력 → **프레임 1장 수신 확인**) → 4) 텔레그램(→ getMe 확인)
   → 5) 이메일(선택) → 6) 필수 보호구 → 7) 파일 확인.
   - 비밀번호·토큰은 화면에 **다시 찍히지 않습니다**. USB 에도 저장되지 않습니다(기기의 `C:\VIGENT\app\config\notify.yaml`·`data\camera_secrets.json` 에만).
4. 이어서 **인수시험**이 돕니다.
   - **자동 A1~A8**: 서비스 · `/health` · 모델 로드 · **GPU 사용** · 카메라 프레임 · 알림 채널 · 시험 메시지 전송 · 종합. **하나라도 실패 = 설치 미완료**.
   - **사람 확인 H1·H2**: "카메라 앞에 3초 서 주세요" 뒤 검출을 봤는지, 시험 메시지가 폰에 왔는지 y/N. 실패는 **경고**(설치는 완료).
   - 결과는 기기의 `C:\VIGENT\app\data\install_report_<시각>.json` 에 남습니다(USB 아님).

## 2. 설치 뒤 확인

- 브라우저에서 `http://127.0.0.1:8010/health` → `"status": "healthy"`, `"phase": "ready"`, `"gpu": {"torch_cuda": true, "fallback": false}`.
- 대시보드 `http://127.0.0.1:8010/safety` 에 **붉은 배너**가 있으면 그대로 두지 마세요:
  - "**GPU 미사용 — CPU 로 추론 중**" → 드라이버(≥580)·CUDA 교체 확인. 이 상태는 인수시험 미달입니다.
  - "**알림 채널 불능**" → 토큰·chat_id 확인.

## 3. 다시 하기 · 제거

| 하고 싶은 것 | 방법 |
|---|---|
| 마법사 다시 | `C:\VIGENT\python\python.exe C:\VIGENT\app\scripts\deploy\setup_wizard.py` |
| 인수시험 다시 | `C:\VIGENT\python\python.exe C:\VIGENT\app\scripts\deploy\acceptance_test.py` (사람 확인만: `--only-human`) |
| 업데이트 | 새 USB 의 `설치.bat` 을 다시 관리자 권한으로 — 데이터·설정 보존 |
| 제거 | USB `installer\uninstall.ps1` 을 관리자 PowerShell 에서 — 설정·데이터 백업 여부를 묻습니다 |

## 4. 하지 말 것

- 기기에서 `git` 을 쓰지 않습니다. 코드는 USB 태그 스냅샷으로만 들어갑니다.
- `C:\VIGENT\app\config\tuning.yaml` 을 손으로 고치지 않습니다(마법사가 필수 보호구만 기록합니다).
- 카메라 영상은 기기 밖으로 나가지 않습니다. 클라우드 분석 설정을 켜지 마세요.

## 5. 아직 안 되는 것 (1차 범위)

- PoE·고정 IP 대역·ONVIF 자동 검색·화면 마법사·원격 상태 수집(설계서 §10).
- 마법사는 명령줄입니다. 실카메라·실토큰 검증은 개발기에 RTSP 카메라가 없어 **가짜 입력으로만** 시험했습니다.
