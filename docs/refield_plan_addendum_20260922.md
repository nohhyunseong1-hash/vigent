|---|---|---:|---|---|
| **T1** | **원거리 진입** | 3분 | 사람이 화면 **가장자리에서 안쪽으로** 걸어 들어옴. 박스 높이 10% 미만에서 시작해 커지게. 진입 직후 몇 프레임이 잡히는지가 핵심 | A(확정 지연) |

## 4. ★검증 게이트 — 이것을 통과하기 전에 철수하지 않는다

절차서에 **다음 문장을 그대로 넣는다.**

> **장면이 끝날 때마다** 그 장면 폴더에 대해 아래를 돌린다. 통과하지 못하면 **그 장면을 다시 찍는다.**
> ```
> python scripts/check_raw_capture.py runs/field_<날짜>/<장면>
> ```
> **철수 직전** 전체를 한 번 더 돌린다. **전 장면이 통과하기 전에는 현장을 떠나지 않는다.**
> ```
> python scripts/check_raw_capture.py runs/field_<날짜>
> ```

`check_raw_capture.py` 가 보는 것(이미 구현돼 있음)
- `original.mp4` 존재·크기·**실제로 열려서 프레임이 나오는지**
- `raw/still_*.jpg` 존재 · 오버레이 스틸과 **개수 일치**
- `dets.jsonl` 존재·비어 있지 않음
- `dets` 행 수와 원본 프레임 수의 어긋남 경고

★**적어 두는 것과 만드는 것은 다르다.** 1차 절차서에도 "녹화 회수(필수)"라고 적혀 있었으나
확인하는 장치가 없어 929프레임을 찍고도 원본이 한 장도 남지 않았다(CLAUDE.md 규칙 11).
