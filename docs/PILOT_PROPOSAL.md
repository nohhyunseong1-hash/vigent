# VIGENT 파일럿 제안서 (초안)

> 대상: 공장·건설현장 등 잠재 파일럿 고객. **가장 검증된 단일 기능**으로 시작하는 최소 위험 파일럿을 제안한다.
> 원칙(정직): 아래 수치는 **공개 데이터셋·자체 실측** 기준이며 **현장 정확도는 파일럿에서 처음 검증**된다. 과장하지 않는다.

---

## 1. 무엇을 제공하나 — "위험구역 침입 경보" 단일 기능

지정한 **위험구역**(예: 크레인 인양 반경, 프레스 앞, 차량 동선)에 **사람이 들어오면 경보**하는 기능 한 가지로 파일럿을 시작합니다. 이 기능을 고른 이유는 **자체 검증이 가장 앞서 있기 때문**입니다.

- 소형(원거리) 작업자까지 잡기 위한 **위험구역 한정 재검출(타일링)** 로, 크레인 실사고 영상에서 소형작업자 검출률을 **0% → 89~95%** 로 끌어올린 것을 실측했습니다.[^tile]
- 침입자에게 **안정적인 추적 ID**를 부여해 "누가 언제 얼마나 머물렀는지"를 식별합니다. 최근 추적기를 교체해 다중 작업자 상황의 ID 단편화를 크게 줄였습니다(같은 영상에서 ID 스위치 13→0).[^track]
- 경보는 **화면·소리·외부 알림(텔레그램/웹훅)** 으로 전달됩니다.

**중요 경계(법적·기능적):** VIGENT는 **보조·감시 계층**입니다. 비전 AI는 확률적이라 **인증 안전기능(방호장치·안전 PLC)을 대체하지 않습니다.**[^boundary] 파일럿은 기존 안전조치에 **추가되는 감시 신호**입니다.

## 2. 고객이 준비할 것 (최소 요구사항)

| 항목 | 내용 |
|---|---|
| **카메라** | 위험구역이 잘 보이는 위치에 **RTSP 지원 IP 카메라 1대**(기존 CCTV 활용 가능). 광역 조망이면 소형작업자용 타일링 on. |
| **네트워크** | 카메라 → 처리 장비(현장 미니PC/서버) 간 유선/무선 연결. 인터넷은 **선택**(로컬 처리 기본, 클라우드 미사용 기본). |
| **설치 공간·전원** | 처리 장비 1대 설치 공간·전원. (GPU 사양은 별도 [인프라 조달 사양서](INFRA_REQUIREMENTS.md) 참조) |
| **접근 권한·담당자** | 카메라 배치·구역 지정·경보 확인을 함께할 현장 담당자 1인. |
| **개인정보 동의** | 근로자 영상 처리에 대한 **고지·동의·노사협의**([개인정보 정책 초안](PRIVACY_POLICY_DRAFT.md) 연계). |

## 3. 우리가 보장하는 것 / 보장하지 못하는 것 (정직)

**보장(할 수 있는 것):**
- 위험구역 침입 순간의 **경보·증거 프레임 기록**. 로컬 저장 기본(영상 외부 유출 없음).[^local]
- 소형작업자 대응 타일링·안정적 추적 ID 등 **검증된 검출·추적 파이프라인** 제공.
- 24시간 무인 안정성 점검 도구·절차(장시간 크래시·메모리 누수 감시).[^soak]

**보장하지 못하는 것(정직):**
- **오탐/미탐 0을 보장하지 않습니다.** 타일링의 현장 오탐율은 **아직 실측 전**이며, 파일럿 초기에 함께 측정·조정합니다.[^tile]
- **초기 조정 기간이 필요합니다**(보통 수일~수주): 카메라 각도·위험구역 경계·검출 임계값을 현장에 맞춰 튜닝. 이 기간의 정확도는 안정화 후보다 낮습니다.
- **낙상·쓰러짐 자동감지는 현재 제품에 포함되어 있지 않습니다.** 정상 동작(착석 등)에서 오탐이 지속되고 재보정에 필요한 참조 영상(실제 낙상 클립)이 없어 2026-08 제거했습니다. 광역 CCTV 해상도(작업자 26~64px)에서는 애초에 자세 기반 판별이 물리적으로 어렵다는 것도 실측으로 확인했습니다 — 재도입하려면 참조 클립 확보·다인 포즈 기반 재구현·근접 카메라가 필요합니다.[^fall]
- **보호구 미착용(특히 안전모)·지게차 협착**은 별도 기능이며 **재학습 전까지 정확도가 낮거나 비활성**입니다(안전모 미착용 놓침 ≈44%, 지게차 검출 비활성).[^ppe]

## 4. 파일럿 기간·성공 기준·데이터 활용

- **기간(제안):** 4~8주. 1주 설치·조정 → 2~6주 관측·측정 → 종합 리포트.
- **성공 기준(현장 합의):** 위험구역 침입 이벤트에 대해 (a) **미탐률**과 (b) **오탐률(건/일)** 을 현장 실측하고, 상호 합의한 실용 임계(예: 실침입 재현율 목표 + 오탐 상한)를 만족하는지. *절대 수치는 현장 데이터로 정한다(사전 약속 금지 — 규칙7).*
- **안정성:** 관측 기간 중 **크래시 0 · 워커 생존 · 메모리 누수 없음**을 자동 판정 리포트로 확인.[^soak]
- **데이터 활용 동의:** 파일럿 영상·이벤트는 **로컬 저장**이 기본이며, 정확도 개선(재학습)에 활용하려면 **별도 명시 동의**를 받습니다. 보관기간·비식별화 방침은 개인정보 정책 초안을 따릅니다(얼굴 비식별화·자동파기는 **구현 예정 항목**임을 명시).[^privacy]

## 5. 고객에게 돌아가는 가치

- **위험구역 상시 감시**: 사람이 놓치기 쉬운 반복 위험(인양 반경 진입 등)을 24시간 자동 감시.
- **증거 기반 안전관리**: 침입 이벤트·증거 프레임 기록 → 아차사고 분석·안전교육 자료.
- **안전서류 자동화(확장 옵션)**: 감지 이벤트로 위험성평가서 초안을 자동 생성(법령 근거 인용 포함) — 파일럿에서 시연 가능.
- **낮은 진입 장벽**: 기존 CCTV·로컬 처리로 시작, 인증 안전기능은 그대로 유지하며 **보조 신호만 추가**.
