## 1. 결론

| 순위 | 항목 | 이유 |
|---|---|---|
| **1** | **CPU** | 병목이 여기다. 카메라당 **1.55코어**(현행 3슬롯·2fps·GPU 있음, ★[Q10] ORT 스핀 제거 기본 적용 후 실측. 재현 1.52) |
| **2** | **저가 GPU 를 반드시 넣을 것** | GPU 는 성능이 아니라 **CPU 절약 장치**다 — 없으면 CPU 를 **2.2배** 써야 한다(§5) |
| 3 | RAM 16GB · SSD 256GB | 병목 아님 |

### 1-1. 이번 개정의 핵심 3줄

> **① VRAM 하한이 6GB → 4GB 로 내려갔다.** 실측 VIGENT 단독 VRAM 은 **1.4GB**다.
> 이전 "3.2GB" 는 Windows 데스크톱·VS Code 등이 포함된 **GPU 총량 오독**이었다(V1 §4).
> → **GTX 1650(4GB) 급이면 충분하다.**
>
> **② GPU 없이도 성립한다. 그러나 훨씬 비싸다.** GPU-less 는 카메라 1대에
> **i7-10700급**(환산 7.06)이 필요한데, GPU 를 넣으면 같은 일을 **i5-8500급**(3.12)이 한다.
> 중고 GTX 1650 이 10~18만원인데 CPU 두 단계 값이 그보다 크다 → **GPU 를 넣는 게 정답.**
>
> **③ 기능을 줄여도 CPU 는 거의 안 준다.** 4슬롯→1슬롯으로 잘라도 CPU −15%,
> 한계 대수는 8.3→8.8대로 **1대도 안 는다**(V1 §2-1). 기능 축소는 **VRAM·지연** 카드지
> **대수** 카드가 아니다.

## 2. 산정 기준 — "코어 수"가 아니라 "이 PC 코어 환산"

### 2-1. 기준 CPU

| 항목 | 값 |
|---|---|
| 기준 CPU | **AMD Ryzen 9 9900X** (12코어 / **24 논리스레드**, 4.4GHz) |
| PassMark **싱글스레드** | **4,672** |
| PassMark **CPU Mark**(멀티) | **54,322** |

> 출처: [PassMark — Ryzen 9 9900X](https://www.cpubenchmark.net/cpu.php?cpu=AMD+Ryzen+9+9900X&id=6171) (2026-08-18 조회). 점수는 표본이 쌓이며 바뀐다 — 조회 시점 값으로 다시 계산할 것.

### 2-2. 환산 공식

```
환산코어 A = (후보 논리스레드 수) × (후보 PassMark 싱글스레드 ÷ 4,672)
환산코어 B = 24 × (후보 PassMark CPU Mark ÷ 54,322)

채택 환산코어 = min(A, B)        ← ★반드시 작은 쪽(보수적)
```

A 는 SMT 를 실코어처럼 세어 과대평가하기 쉽고, B 는 벤치 구성이 우리 작업과 다르다.
작은 값을 쓰면 **어느 쪽 오차에도 안전한 방향**으로 기운다.

### 2-3. 대수 산정

```
한계 N  =  환산코어 × 0.70 ÷ (카메라당 코어)
권장 N  =  한계 N × 0.75
필요 환산코어 = 원하는 대수 × 카메라당 코어 ÷ 0.70
```

**검산**: 기준 CPU 환산 24.0, 카메라당 1.55코어(Q10 적용 후) → 한계 **10.9대**.
⚠C5 **실측 한계 7대**는 스핀 제거 **전**(카메라당 2.10) 측정이다 — 당시 공식 예측 8.0대와
부합했다. 새 한계(10.9대)는 **공식 예측일 뿐 capacity_probe 재실측 전**이므로,
구매 판단에는 보수적으로 쓴다.

## 5. ★본체 + GPU 분리 구매 전략

### 5-1. 왜 분리해서 사는가

| | 필요 환산코어(1대, 현행 기능) | 만족하는 최저 CPU |
|---|---|---|
| **GPU 있음** | **2.21** ★Q10 실측 | **i5-8500급**(3.12) — 여유 41% |
| GPU 없음 | 6.33(스핀 제거 전 실측) | i7-10700급(7.06) |

**GTX 1650 4GB 중고가 10~18만원**인데, i5-8500급 본체와 i7-10700급 본체의 가격 차이는
그보다 크다(§7). → **싼 본체 + 저가 GPU** 조합이 **비싼 CPU 단독**보다 유리하다.

### 5-2. ⚠ 중고 사무용 본체의 함정 4가지 — 각각 확인 방법 포함

중고 사무용 PC 는 대부분 **슬림형(SFF)** 이라 그래픽카드를 못 꽂는 경우가 많다.
**본체를 사기 전에 반드시 4가지를 확인**한다.

| # | 함정 | 왜 문제인가 | **확인 방법** |
|---|---|---|---|
| **1** | **파워 용량** | 사무용 SFF 파워는 **180~300W** 가 흔하다. GTX 1650 은 75W 라 대개 괜찮지만, 노후 파워는 정격을 못 낸다 | 케이스를 열어 파워 유닛 **라벨의 정격 W** 확인. 판매글에 없으면 **모델명을 물어 검색**. 250W 이상 권장 |
| **2** | **6/8핀 보조전원** | GTX 1650 **기본형은 보조전원이 필요 없다**(PCIe 슬롯 75W 로 충분). 그러나 **팩토리 OC 모델은 6핀이 달려 있다** — SFF 파워엔 그 케이블이 없을 수 있다 | **카드 사진에서 상단 커넥터 유무**를 본다. **6핀 없는 모델을 고를 것.** 본체 쪽은 파워에서 나온 여유 PCIe 케이블 유무 확인 |
| **3** | **케이스 폭(높이 제한)** | 슬림형은 **하프하이트(로우프로파일)** 카드만 들어간다. 일반 높이 카드는 브래킷이 안 맞는다 | 기존 확장 슬롯 **브래킷 높이**를 본다(일반 12cm / 로우프로파일 8cm). 슬림형이면 **로우프로파일 + 싱글슬롯 GTX 1650** 을 사야 한다(해당 모델 존재함) |
| **4** | **PCIe x16 슬롯** | 일체형·미니PC(NUC류)는 **슬롯 자체가 없다**. 일부 슬림형은 **라이저 카드**로 방향을 꺾어 쓴다 | 판매글 **내부 사진**으로 x16 슬롯을 눈으로 확인. "미니PC"·"베어본"·"올인원" 은 **후보에서 제외** |

★**요약**: **"타워형 또는 미들타워 중고 사무용 본체 + 6핀 없는 GTX 1650"** 이 가장 안전하다.
슬림형을 살 거면 **로우프로파일 카드**로 맞춰야 한다.

### 5-3. GPU 요구 사양 (실측 근거)

| 지표 | 실측 | 함의 |
|---|---|---|
| VIGENT 단독 VRAM(3슬롯) | **1,397 MiB** | **4GB 카드로 충분**(2.9배 여유) |
| 1→8대 VRAM 증가 | **+34 MiB**(카메라당 ~5 MiB) | 대수를 늘려도 VRAM 은 안 는다 |
| GPU util(8대 시점) | **최대 42%**, 대개 20~30% | **GPU 연산은 남아돈다 — 상위 카드는 낭비** |

**필수 조건**: NVIDIA **CUDA** · VRAM ≥ 4GB · **현재 torch(cu130) 지원 아키텍처**.

## 6. ❌ 사지 말아야 할 것

| 사지 말 것 | 이유(실측 근거) |
|---|---|
| **비싼 GPU** | 8대에서도 GPU util 최대 42%, VRAM 1.4GB. 대수가 안 늘어난다 |

| **NVIDIA 아닌 GPU**(Intel Arc·AMD·iGPU) | 서빙이 torch cu130 CUDA 경로다. 타 백엔드 **미측정·미검증** |
| **Jetson·ARM 엣지박스** | Windows 의존 4가지가 깨지고(§8) ARM torch/RF-DETR **미검증** |
| **N100급 4코어 미니PC** | 환산 1.61 — GPU 를 넣어도 필요 2.21 에 **미달** |
| **미니PC·베어본·올인원** | PCIe x16 슬롯이 없어 **GPU 를 못 넣는다**(§5-2 함정 4) |
| **아주 오래된 GPU**(Kepler·Maxwell) | 최신 torch(cu130) 지원 중단 가능 — §9 에서 확인 |

| **i5-10400 본체 + GTX 1650** | 5.29 | 2.21(1대) / **4.43(2대)** | ✅ 1대 / ✅ **2대**(★Q10 으로 상향 — 이전 ❌) | **약 56~64만원** |
| i7-10700급 본체 + GTX 1650 | 7.06 | 4.43(2대) | ✅ 2대(여유 59%) | CPU 단품만 30만 → 본체 **미조사** |
| **i7-10700급 본체, GPU 없음** | 7.06 | 6.33(1대, 스핀 제거 전 실측) | ✅ 1대뿐 | 위와 같은 본체값에 GPU 만 절약 |
| N100급 미니PC | 1.61 | 2.21 | ❌ | — |

★**같은 i7-10700급 본체라면, GPU 를 빼서 1대를 돌리는 것보다 GTX 1650(10~18만원)을 넣어
2대를 돌리는 편이 압도적으로 낫다.** GPU-less 는 "GPU 를 도저히 못 넣는 경우"의 대안이지
비용 최적해가 아니다.

⚠**2대 판정은 공식 계산이다.** i5-10400 실기에서 2대를 실측(§9-4 인수시험)하기 전까지
판매 약속에 쓰지 말 것 — 여유가 16%(5.29 vs 4.43)로 얇다.

⚠ **가격은 우리가 검증한 것이 아니다.** 실제 매물·상태·A/S 조건에 따라 달라진다.

> ⚠️ **측정 전 반드시 확인할 전제 3가지** (2026-08-20 학원 현장 노트북 준비 중 확인)
>
> 1. **모의 소스 영상이 있어야 한다** — `runs/rfdetr/accident/*.mp4`. `runs/` 는
>    `.gitignore` 라 clone 만으로는 없다. 개발 PC 에서 복사해 올 것.
>    ★정적 이미지·합성 영상 대체 금지 — 검출 부하가 가벼워 **한계 N 이 후하게 나온다**.
> 2. **★BitLocker 암호화가 진행 중이면 돌리지 말 것.** 최초 암호화는 CPU·디스크를
>    지속적으로 쓰기 때문에 검출 지연이 부풀려져 **한계 N 이 실제보다 낮게 나온다**.
>    `Get-BitLockerVolume -MountPoint C: | Select EncryptionPercentage` 가 **100** 이고
>    `VolumeStatus=FullyEncrypted` 인 것을 확인한 뒤 측정한다.
>    (같은 이유로 백신 전체검사·Windows 업데이트·대용량 파일 복사 중에도 돌리지 않는다.)
> 3. **전원·전력 상태** — 충전기 연결 + 고성능 전원 계획 활성. 노트북은 배터리 모드에서
>    CPU 를 제한하므로 배터리로 재면 값이 낮게 나온다. 노트북에는 발열 스로틀링도
>    함께 관측해 기록할 것(데스크탑 기준 수치와 직접 비교하면 안 된다).
