# 70. 역할 분담과 주간 루틴

## 역할과 담당 폴더 (파일 충돌을 구조적으로 예방)

> 감사 결과 비전·에이전트는 **서로 import하지 않아**(느슨한 결합) 폴더로 나누면 충돌이 거의 없습니다.

| 역할 | 담당 폴더/파일 | 대표 티켓 |
|---|---|---|
| **비전(L1)** | `vigent-core/rfdetr_service.py`·`worker.py`·`proximity.py`·`ergonomics.py`·`zone_*.py`·`routers/{detect,zone,ppe}.py`·`weights/` | V-01~V-08 |
| **에이전트(L2)** | `vigent-core/agents/`·`routers/{safety_core,tbm,incident}.py`·`eval/golden/`·`config/corpus/` | A-01~A-08 |
| **문서·사업** | `docs/`·`docs/team/`·제안서·조달 | 제안·인프라·개인정보 |
| **현장검증** | 현장 영상 수집·오탐 분류·라벨(데이터, 코드 아님) | V-05·A-05 |

- **공유부를 바꿀 땐 반드시 상대 역할과 조율**하고 PR 리뷰를 양쪽에서 받습니다.
- (참고) `CODEOWNERS` 파일로 이 규칙을 자동화할 수 있습니다 — GitHub에 올린 뒤 도입 검토.

## 주 1회 30분 동기화 미팅 — 아젠다 템플릿

```
1. 지난주 완료 티켓 (각자 1분)              — 5분
2. 병목 3개(V-01·V-02·A-01) 진행 점검       — 10분
3. 교차 의존 막힘 확인 (한쪽 늦으면 양쪽 정지) — 5분
4. 이번 주 각자 목표 티켓 1개 선언           — 5분
5. 위험 신호(조기 경보) 공유                 — 5분
```

## 데일리 3줄 보고 양식 (팀 채널)

```
[이름] YYYY-MM-DD
어제 한 것 : (티켓 번호 + 한 줄)
오늘 할 것 : (티켓 번호 + 한 줄)
막힌 것    : (없으면 '없음')
```

## 티켓 진행 상태 관리 — 방식 선택

- **A. 문서 체크박스**: 이 문서들의 `[ ]` 체크박스를 직접 채움. 간단하나 여러 명이 동시에 고치면 충돌.
- **B. GitHub Issues**: 티켓 하나 = 이슈 하나. 담당·상태·댓글이 자동 기록되고 PR과 연결됨.

> **권장: B(GitHub Issues).** 이유 — (1) 충돌 없음(각 이슈 독립), (2) 누가 뭘 하는지 한눈에, (3) PR·커밋과 자동 연결로 이력이 남음. 초보 팀도 "이슈 만들고 → 담당 정하고 → 완료 시 닫기"만 익히면 됩니다.
