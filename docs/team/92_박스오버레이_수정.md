## 4. 중복 박스가 생기는 정확한 경로 (코드)

`agents/guard.py`의 detect()는 `_nms(367) → _suppress_vehicle(368) → _track(369)` 순서입니다. 중복이 생기는 조건:

1. 같은 사람이 **두 모델(person 슬롯 + ppe 슬롯의 'Person')**에 잡혀 박스 2개가 됩니다(라벨은 통일됨, `guard.py:63`).
2. 두 박스의 겹침이 **IoU 0.45~0.55**이면:
   - `_nms`(기본 IoU **0.55**, `guard.py:82·87`) → 0.55 미만이라 **둘 다 통과**(다른 물체로 봄).
   - `_track`(`guard.py:246`): conf 높은 박스1이 트랙 T1에 매칭되고 `used`에 등록(`guard.py:261`). 박스2는 T1이 이미 쓰여서(`guard.py:254` `if id(t) in used: continue`) 매칭 실패 → **새 트랙 T2 생성**(`guard.py:272~274`).
   - 결과: 한 사람에 **트랙 2개(T1·T2) = 박스 2개**.
3. 근본: `_nms`의 0.55와 `TRACK_IOU` 0.45(`guard.py:117`)가 **"같은 물체" 기준을 다르게** 잡아, 0.45~0.55 구간이 샙니다.

## 판정: ✅ 성공 (범위 내 목표 달성, 회귀·병합사고 없음)

- 같은 사람·다른 소스 → **1개로 합쳐짐**(0.45·0.50 개선). 다른 두 사람 → **불변**(내 병합은 same-source 스킵). 실영상 사람 수 불변, 테스트·골든 무회귀.
- **정직한 캐비어트**: 사용자 성공기준 "다른 두 사람 IoU 0.55 → 2 유지"는 **수정 전부터 1**입니다 — 이는 내가 안 건드린 기존 `_nms(0.55)` 소관이며, 이번 수정은 그 값을 **악화시키지 않았습니다**(케이스 D 전 구간 불변). IoU 0.55(55% 겹침)는 사실상 같은 물체라 nms 병합이 방어 가능. 이 지점을 더 낮추려면 **별도 티켓(nms 0.55 재검토)** 필요.
