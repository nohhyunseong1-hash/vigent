# 97. 웹캠 블러 줄이기 — 노출·조명 안내 (빠른 이동 검출 안정화)

> 대상: `/safety-local` 등 웹캠 라이브뷰. 빠르게 움직일 때 박스가 흔들리거나 겹쳐 보이는 문제의 **검출 계층 원인(모션블러)**을 줄이는 현장 조치.
> 근거: 2.2 측정 — 표시 평활(One-Euro)로 빠름 오차를 6.6→4.4px까지 줄였으나, 잔여는 **블러로 검출 자체가 흔들리는 한계**. 이는 코드가 아니라 **촬영 조건**으로 완화한다.

---

## 왜 블러가 생기나 (한 줄)
웹캠이 **자동 노출**로 어두운 환경에서 셔터를 오래 열면(노출 길어짐), 그 시간 동안 피사체가 움직여 **한 프레임이 번진다**(모션블러). 번진 프레임에선 검출기가 박스를 매 프레임 다르게 잡아 **흔들림·중복**이 생긴다.

## 조치 — 밝게 하면 노출이 짧아진다
1. **조명을 밝게**: 작업 구역 조명을 켜거나 밝은 쪽을 향하게 한다. 밝을수록 카메라가 **셔터를 짧게** 열어 블러가 준다(가장 쉬운 방법).
2. **역광 피하기**: 창문·조명을 등지지 않게 한다(자동 노출이 배경에 맞춰 인물이 어두워지고 노출이 길어짐).
3. (선택) **노출/셔터 고정**: macOS 카메라 설정 앱이나 촬영 앱에서 노출을 수동으로 낮추거나 셔터를 빠르게 고정하면 블러가 확실히 준다(밝기는 다소 어두워지는 트레이드오프).

## 확인 절차 (전/후 측정 — 규칙7)
조명 바꾸기 **전과 후**로 각각 10초 클립을 녹화해 **선명도(블러 정도)**를 수치로 비교한다.

1. 어두운 조건에서 녹화:
   ```
   /opt/anaconda3/bin/python3 benchmarks/record_fast.py --out runs/rfdetr/test_dim.mp4
   ```
   (좌우로 빠르게 움직이며 10초)
2. 조명을 밝게 한 뒤 다시 녹화:
   ```
   /opt/anaconda3/bin/python3 benchmarks/record_fast.py --out runs/rfdetr/test_bright.mp4
   ```
3. 두 클립의 선명도(라플라시안 분산 — 높을수록 선명·블러 적음)를 비교:
   ```
   /opt/anaconda3/bin/python3 benchmarks/blur_check.py runs/rfdetr/test_dim.mp4 runs/rfdetr/test_bright.mp4
   ```
   → **bright 의 선명도 중앙값이 dim 보다 높으면** 블러가 준 것이다. 그 상태에서 `/safety-local` 라이브뷰의 박스 흔들림·중복이 함께 줄어드는지 육안 확인한다.
