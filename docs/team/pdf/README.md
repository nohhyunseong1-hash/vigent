## PDF가 안 열리거나 페이지 번호가 필요할 때 (폴백)

PDF는 A4·여백 20mm로 만들었지만, **정확한 페이지 번호(N/총 M)**가 필요하거나 재생성하려면 **HTML을 브라우저로 인쇄**하세요:

1. 같은 폴더의 `.html` 파일을 **크롬으로 엽니다**(더블클릭).
2. **Cmd+P**(맥) / **Ctrl+P**(윈도우) → 대상 **"PDF로 저장"**.
3. 옵션에서 **용지 A4 · 여백 기본 · "머리글/바닥글" 체크**하면 페이지 번호가 하단에 붙습니다.
4. 저장.
