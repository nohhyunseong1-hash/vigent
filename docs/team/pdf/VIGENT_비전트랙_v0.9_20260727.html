00. 시작하기 전에 (3분 요약)

이 문서는 팀원 전원(대표 포함)이 가장 먼저 읽는 문서입니다. 바이브코딩·팀 프로젝트가 처음이어도 괜찮습니다.

VIGENT가 뭘 만드는 회사인가 (5줄)

  1. VIGENT는 공장·건설현장의 CCTV 영상을 AI가 보고 위험을 잡아내는 산업안전 플랫폼입니다.
  2. 카메라가 "위험구역에 사람이 들어왔다 / 보호구를 안 썼다 / 불·연기가 났다"를 자동으로 감지해 경보합니다. (이것을 비전(Vision, L1)이라 부릅니다.)
  3. 감지 결과로 위험성평가서 같은 안전 서류를 AI가 자동 작성합니다. (이것을 에이전트(Agent, L2)라 부릅니다.)
  4. 즉 "보는 눈(비전) + 판단하는 머리(에이전트)"가 한 시스템으로 붙어 있습니다.
  5. VIGENT는 보조 감시 도구입니다 — 법으로 정해진 안전장치(방호장치 등)를 대체하지 않고, 추가로 지켜보는 신호를 줍니다.

지금 어디까지 왔나 (3줄)

  • 비전·에이전트 코드와 자체 테스트(82개 통과)는 갖춰졌고, 동시부하 크래시(F-14) 같은 큰 안정성 문제는 해결했습니다.
  • 하지만 실제 현장 CCTV로 정확도를 잰 적이 거의 없습니다(실영상 검증 1건). 공개 데이터셋 수치만 있습니다.
  • 감지 클래스는 3클래스 가동(person·PPE·fire/smoke) + forklift(지게차)는 재학습 대기입니다.

앞으로 뭘 할 건가 (3줄)

  • 비전(L1): 현장 영상으로 정확도(오탐·미탐)를 재고, 부족한 클래스(안전모 미착용 등)를 재학습해 KISA 인증 기준(F1 ≥ 0.90)을 향합니다.
  • 에이전트(L2): AI가 만든 안전서류의 품질을 계측하고, 잘못된 법령 인용(환각)을 막고, 비전 감지와 자동 연동합니다.
  • 두 트랙이 만나 파일럿(시범 설치) → 유상 납품으로 갑니다. 상세 단계는 10·20 문서에 있습니다.

지금 당장 팔 수 있는가? (정직한 답 3줄)

  3. 먼저 필요한 것: 현장 카메라 1대 + 실영상 오탐율 측정 + GPU 장비. (상세: docs/PILOT_PROPOSAL.md·docs/INFRA_REQUIREMENTS.md)

  • S3 — 증거물: 없음. 선행: S0~S2. 실패 리스크: 폐쇄망에서 모델·의존성 누락 → 대비책: weights 동봉 오프라인 설치 스크립트 사전 검증.
  • S4 — 증거물: 없음. 선행: S1·S3 필수. 실패 리스크: NO-Hardhat F1이 0.90에 크게 못 미침(현재 R56) → 대비책: V-03(재학습)을 가장 먼저 착수(리드타임 최장).
  • S5/S6 — S4 취득 후. 리스크·대비책은 30_통합_로드맵.md에서 통합 관리.
