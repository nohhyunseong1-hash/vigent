# 50. 완전초보 온보딩 (가장 자세하게)

> 컴퓨터에 **아무것도 안 깔린 상태**를 가정합니다. macOS와 Windows를 나눠서 씁니다.
> 상세 개발 환경은 `docs/ONBOARDING.md`도 함께 참고합니다(이 문서는 그 초보자용 버전입니다).

---

## ⛔ 이거 없으면 아무것도 안 됩니다 (제일 먼저)

git으로 코드를 받아도 **아래 2개는 안 따라옵니다.** 반드시 팀에서 따로 받아 넣으세요.

### ① `.env` (비밀키 파일)
- git에 올리면 안 되는 API 키가 들어갑니다 → **각자 만들어야** 합니다.
```bash
cp .env.example .env
```
실행하면 이런 게 보입니다:
```
(아무 메시지 없이 .env 파일이 생깁니다)
```
- 그다음 `.env`를 열어 팀에게 받은 키를 채웁니다(예: `OPENAI_API_KEY`). **키는 절대 채팅·git에 쓰지 마세요.**

### ② 모델 가중치 `weights/` (812MB, 18개 파일)
- 용량이 커서 git에 없습니다. **없으면 검출이 엉뚱하게 동작(COCO 폴백)해 정확도가 급락합니다**(과거 F-8 사고).
- 팀 공유 위치(클라우드 드라이브/USB)에서 받아 **`vigent-core/weights/`** 폴더에 넣습니다.
- 확인:
```bash
ls vigent-core/weights/ | wc -l
```
실행하면 이런 게 보입니다:
```
18
```
> `[스크린샷 자리]` weights 폴더에 파일 18개가 들어있는 모습

**이 2개가 준비되기 전에는 서버가 제대로 안 돕니다.** 아래 설치를 먼저 하고, 이 2개로 마무리하세요.

## macOS

### 1. 터미널 열기
- `Cmd(⌘) + Space` → "터미널" 입력 → Enter.
> `[스크린샷 자리]`

### 2. 내 위치 확인·이동·목록
```bash
pwd                    # 지금 어느 폴더인지
cd ~/Desktop/VIGENT    # VIGENT 폴더로 이동
ls                     # 폴더 안 목록 보기
```
실행하면 이런 게 보입니다:
```
/Users/본인이름/Desktop/VIGENT
CLAUDE.md   README.md   vigent-core   docs   ...
```

### 3. Git 확인·설치·설정
```bash
git --version          # 설치돼 있으면 버전이 뜸
```
- 안 깔렸으면: `xcode-select --install` 실행 → 설치 창을 따라갑니다.
- 최초 1회 설정:
```bash
git config --global user.name "본인이름"
git config --global user.email "본인이메일"
```

### 4. Python·가상환경·의존성
```bash
python3 --version                    # 3.11~3.13 권장
python3 -m venv .venv                 # 가상환경 만들기
source .venv/bin/activate             # 활성화 (앞에 (.venv) 가 붙음)
pip install -r requirements.txt       # 의존성 설치
```
- opencv 정리(중요, `docs/ONBOARDING.md` §2.2와 동일):
```bash
pip uninstall -y opencv-python opencv-contrib-python
pip install --force-reinstall --no-deps opencv-contrib-python-headless==4.13.0.92
```

### 5. 리포 내려받기 (처음 한 번만)
```bash
git clone <여기에 저장소 주소> VIGENT
cd VIGENT
```

### 6. Claude Code 설치·실행
```bash
claude                                # 프로젝트 폴더에서 실행
```
> `[스크린샷 자리]` Claude Code 시작 화면

### 7. 첫 실행 성공 확인
- 서버 켜기:
```bash
./run.sh
```
- 다른 터미널에서:
```bash
curl http://127.0.0.1:8010/health
```
실행하면 이런 게 보이면 **성공**입니다:
```
{"status":"ok","loaded":true, ... }
```
- `"loaded":true` 가 보이면 모델이 제대로 올라간 것입니다. (안 뜨면 §가중치 확인)

## Windows

> ⚠️ 이 프로젝트는 macOS에서 개발됐습니다. Windows에서 처음 켤 때 잔가지 조정이 필요할 수 있습니다. **NVIDIA GPU가 있으면 검출이 더 빠르고 재학습도 가능**합니다(상세 `docs/INFRA_REQUIREMENTS.md`).

### 1. 터미널(PowerShell) 열기
- `시작` 버튼 → "PowerShell" 입력 → Enter.
> `[스크린샷 자리]`

### 2. 내 위치 확인·이동·목록
```powershell
Get-Location                 # 지금 폴더 (pwd 대신)
cd $HOME\Desktop\VIGENT      # 이동
dir                          # 목록 (ls 대신 dir)
```

### 3. Git 확인·설치·설정
```powershell
git --version
```
- 안 깔렸으면: <https://git-scm.com> 에서 설치.
```powershell
git config --global user.name "본인이름"
git config --global user.email "본인이메일"
```

### 4. Python·가상환경·의존성
```powershell
python --version                     # 3.11~3.13
python -m venv .venv
.venv\Scripts\activate               # 활성화 (macOS와 경로 다름)
pip install -r requirements.txt
```
- ⚠️ **로컬 VLM(mlx)은 애플 전용이라 Windows에서 설치·실행 안 됩니다.** `requirements-optional.txt`의 mlx 줄은 건너뛰고, VLM은 클라우드(`OPENAI_API_KEY` + `.env`의 `VIGENT_CLOUD_VLM=1`)로 씁니다.
- ⚠️ **NVIDIA GPU면 torch를 CUDA용으로 따로 설치**하세요(자세히는 `docs/INFRA_REQUIREMENTS.md`).

### 5·6·7. clone·Claude·실행
```powershell
git clone <여기에 저장소 주소> VIGENT
cd VIGENT
claude
```
- 서버 실행 후 확인:
```powershell
curl http://127.0.0.1:8010/health
```
`"loaded":true` 가 보이면 성공.

## 자주 나는 에러 5가지와 대처

| 증상 | 원인 | 대처 |
|---|---|---|
| `Permission denied` | 실행 권한 없음 | `chmod +x run.sh` (mac) / 관리자 PowerShell |
| `command not found: claude` / `python` | 미설치·경로 문제 | 재설치, 터미널 새로 열기 |
| `Address already in use` (포트 8010) | 이미 서버가 떠 있음 | 기존 프로세스 종료 후 재실행 |
| `ModuleNotFoundError` | 가상환경 미활성 | `source .venv/bin/activate`(mac)/`​.venv\Scripts\activate`(win) |
| 검출이 안 됨 / `"loaded":false` | **모델 가중치 없음** | `vigent-core/weights/`에 812MB 복사(맨 위 ② 참고) |

## 막혔을 때 행동 순서
1. **에러 메시지 전체를 복사**한다 (일부만 X).
2. **Claude Code에** "이 에러가 났어" + 붙여넣기 → 원인·해결 요청.
3. 그래도 안 되면 **팀 채널에 에러 전문을 공유**한다.
