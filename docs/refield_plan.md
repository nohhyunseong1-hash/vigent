### 왜 이 구성인가
- **R3·R4 를 짝으로** 찍어야 캐빈 재학습(⑤)의 전후 비교가 성립한다. 카메라를 옮기면 못 쓴다.
- **R5 가 없으면 ①은 또 못 잰다.** 1차에서 "모든 장면에 지게차가 실재해 조건 미성립"으로
  측정하지 못했다. 이번에는 **분모를 만드는 것이 목적**인 장면을 따로 둔다.
- R1 은 안전 관련 최우선 결함(지면 사람을 운전자로 오인)의 정답지다.

### 촬영 조건
- 카메라·설치 높이·화각은 **1차와 같게** 한다(비교 가능성). 바꿔야 하면 **바꾸기 전후를 둘 다** 찍는다.
- 각 장면 시작 때 **장면 이름을 말하거나 종이에 적어 화면에 보여준다**(대본 대조용).
- 위험구역은 1차의 **v2 작도를 그대로** 쓴다(재작도하면 §5 결과와 비교 불가).

## 2. ★촬영 중 현장에서 확인할 것

**"찍었다"가 아니라 "원본이 있다"를 확인한다**(CLAUDE.md 규칙 11).
이번 사고가 정확히 이 확인이 없어서 났다.

### 장면 하나가 끝날 때마다 (30초)
```
1) 녹화기 마지막 출력에 이 줄이 있는지 본다:
   [확인] ★원본 original.mp4 12.3MB · 오버레이 8.1MB · 원본 스틸 7장 — 디스크 확인 완료
   ❌ 로 시작하는 줄이 있으면 그 장면은 **다시 찍는다.**

2) 폴더를 직접 열어 눈으로 본다:
   runs/field_<날짜>/<장면>/
     original.mp4   ← ★이게 없으면 헛수고다
     raw/still_001.jpg …   ← 열어서 **박스가 없는지** 확인
     overlay.mp4 · still_*.jpg · dets.jsonl · summary.md

3) raw/still_001.jpg 를 **열어 본다.** 박스가 그려져 있으면 즉시 중단하고 원인을 찾는다.
```

### 철수 전 (5분) — 전 장면 일괄 확인
```bash
python scripts/check_raw_capture.py runs/field_<날짜>
```
장면마다 `original.mp4` 존재·크기·프레임 수, `raw/` 스틸 수를 확인하고
**하나라도 빠지면 실패로 보고**한다. 통과할 때까지 **현장을 떠나지 않는다.**

★1차 때 절차서에는 "녹화 회수(필수)"라고 적혀 있었지만, **원본을 만드는 장치도
확인하는 장치도 없었다.** 적어 두는 것과 만드는 것은 다르다.

|---|---|---|
| 1 | 원본 폴더를 `D:\vigent_field\<날짜>\` 로 이동(복사→해시 대조→삭제) | 저장소·OneDrive 밖 |
| 2 | `python scripts/make_prelabels.py --video <original.mp4> --dets <dets.jsonl> --scene <장면> --out D:/vigent_field/labeling_<날짜> --every 4` | LabelMe 밑그림 |
| 3 | `labelme D:\vigent_field\labeling_<날짜>\<장면>` | 라벨링 시작 |

★2단계의 `--video` 에 **반드시 `original.mp4`** 를 넣는다. `overlay.mp4` 를 넣으면
정답지가 오염된다 — 스크립트는 이것을 자동으로 판별하지 못한다.

(층 구성은 `docs/labeling_plan.md` §3-3)

## 4. 선행 조치 — 녹화기는 **이미 고쳤다**

`scripts/field_recorder.py` (2026-08-29):

| 무엇이 문제였나 | 어떻게 고쳤나 |
|---|---|
| 스냅샷 `fr` 에 **박스를 덮어 그리고** 그것만 저장 → 원본이 그 자리에서 사라짐 | 그리기를 **사본(`vis`)** 에 한다. `fr`(원본)은 손대지 않는다 |
| `overlay.mp4` 만 저장 | `original.mp4`(원본) + `overlay.mp4`(부산물) **둘 다** 저장 |
| 스틸도 오버레이만 | `raw/still_###.jpg`(원본) + `still_###.jpg`(오버레이) 둘 다 |
| 저장 성공을 확인하지 않음 | 종료 시 **파일 존재·크기·스틸 개수 대조**. 하나라도 어긋나면 `❌ 다시 찍어야 한다` 출력 + **종료코드 1** |
| `cv2.imwrite` 무언 실패 | `_save_jpg()` 로 통일 — 인코딩 확인 + 쓴 뒤 존재·크기 확인 |

★**아직 실제 카메라로 시험하지 못했다**(서버·카메라가 있어야 한다).
**방문 당일 첫 장면을 짧게(30초) 찍어 위 확인 절차를 먼저 돌린다.**
그것이 통과해야 본 촬영을 시작한다.
