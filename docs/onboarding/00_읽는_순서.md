### 2시간 뒤 답할 수 있어야 하는 것
- 이 제품이 지금 **성립하는가, 안 하는가** — 근거와 함께
- ⛔치명 결함 **다섯 개**가 무엇인가
- 합류하면 **첫 달에 무엇을 하게 되는가**
- 창업자가 자기 시스템을 **이해하고 있는가**

> ★2시간 경로에 **아키텍처와 코드가 없다.** 의도한 것이다.
> "이 사람과 일할 수 있나"가 "코드가 예쁜가"보다 먼저다.

## 이 자료를 읽는 방식에 대한 부탁

| | |
|---|---|
| ★**나쁜 숫자를 먼저 적었다** | [04]의 첫 표가 약점이다. 감추고 나중에 발견되면 나머지 신뢰도 죽는다고 봤다 |
| ★**"미확인"은 채우지 않았다** | 모르는 것은 모른다고 적혀 있다. 추측으로 메우지 않았다 |
| ★**틀렸던 기록을 지우지 않았다** | 무효 측정·정정 이력이 그대로 남아 있다 |
| **모든 수치에 출처가 있다** | 표본 수·날짜·측정 파일. 출처 없는 수치를 발견하면 **그건 결함이니 지적해 달라** |
| **과장을 찾으면 말해 달라** | 이 묶음의 목적은 설득이 아니라 **정확한 판단 재료 제공**이다 |
