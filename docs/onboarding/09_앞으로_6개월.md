## ★합류하면 무엇을 맡나

후보가 제일 궁금해할 부분이라 구체적으로 적는다.

### 바로 맡을 것 (첫 1개월)

| 영역 | 왜 지금 필요한가 | 크기 |
|---|---|---|
| **F3 프리즈 감지** | ⛔치명적 결함. 시스템이 영구히 "정상"이라 보고하며 아무것도 못 본다 | 작다(프레임 해시 비교 + 워치독) |
| **F9 외부 심박** | ⛔무인 운영 전제와 충돌 | 작다(일일 생존 신고 텔레그램) |
| **F13 재기동 릴레이 OFF** | ⛔사이렌이 안 꺼진다 | 아주 작다(기동 시 OFF 1회) |
| **CI 브랜치 확장** | 지금 작업 브랜치에서 CI가 안 돈다. 사람이 매번 로컬로 돌린다 | 작다 |
| **커버리지 측정 도입** | 검출 경로를 몇 % 덮는지 **아무도 모른다** | 작다 |

★이 다섯은 전부 **작고, 명확하고, 정답지 없이 지금 할 수 있다.**
합류 첫 달에 ⛔치명 결함 3개를 닫는 그림이다.
