# 01. 이게 무엇인가 — 5분

## 한 문장

**산업 현장 CCTV 화면을 2초에 4번 보고, 위험한 장면이면 관리자 휴대폰으로 텔레그램을 보낸다.**

---

## 카메라를 보고 → 무엇을 판단해 → 누구에게 알리는가

| | |
|---|---|
| **본다** | 기존 CCTV 또는 저가 IP 카메라(TP-Link Tapo C200)의 RTSP 스트림. 초당 2프레임만 판정에 쓴다 |
| **판단한다** | ① 보호구 미착용 ② 위험구역 침입 ③ 중장비 근접(협착) ④ 급격동작 ⑤ 무동작 ⑥ 인원 밀집 |
| **알린다** | 현장 관리자·안전관리자의 **텔레그램**. 기록은 전부 남기고 **알림만 요약**한다 |

**실측(2026-08-27 학원 현장 54분)**: 판정 기록 270건 → 휴대폰 알림 19건 = **14.2 : 1**
※출처: `reports/현장테스트_보고서_20260827_v1.2.md` §6 · 표본 1세션

---

## 누구에게 파는가

| | |
|---|---|
| 1차 대상 | **중장비 교육기관·소규모 제조 현장** — 안전관리자 상주가 어려운 곳 |
| 왜 그들인가 | CCTV는 이미 있는데 **사람이 계속 볼 수 없다.** 사고 뒤 "영상 확인"용으로만 쓰인다 |
| 파는 것 | 카메라 교체가 아니라 **기존 화면에 판단을 얹는 것** |

★현재 **유료 고객 0곳 · 파일럿 계약 0건**이다. 학원 1곳에서 시험 촬영(54분)을 1회 했다.

## 이것이 **아닌** 것

- ❌ **인증 안전장치가 아니다.** 프레스 비상정지의 1차 책임은 Type 4 광전자식 방호장치와
  안전 PLC에 있다. 이 제품은 **보조·감시 계층으로 신호만 제공**한다.
- ❌ 추락·낙상 감지 기능 **없다**(제품 범위에서 영구 삭제).
- ❌ 안전대(하네스) 착용 여부를 **볼 수 없다**(모델 출력 클래스에 없음).
- ❌ 엣지 디바이스 제품이 아니다. 현재는 **노트북 1대에서 도는 서버**다.
