# 0. 용어 — 설명 없이 등장하는 것들

> 이 묶음을 처음 보는 사람 기준으로 다시 읽고, **설명 없이 나온 용어**를 모았다.
> 모르는 단어가 나오면 여기부터 본다.

---

## 이 프로젝트에서만 쓰는 말

| 용어 | 뜻 |
|---|---|
| **정답지** | 사람이 프레임마다 직접 라벨링한 정답 데이터(ground truth). **지금 없다.** 이것 때문에 결정 5건이 막혀 있다 |
| **밑그림** | 라벨링을 빨리 하려고 **현재 검출 결과를 미리 그려 넣은 것**. 라벨러는 이걸 고친다 |
| **장면 대본** | "이 장면에서는 안전모를 착용했다"는 **시나리오 설계값**. 프레임 단위 정답이 아니라 장면 단위 정답 |
| **오버레이(overlay)** | 박스·글자를 그려 넣은 영상. ↔ **원본(original)** = 아무것도 안 그린 것 |
| **고아 PPE** | 사람 박스는 없는데 보호구 라벨만 남은 검출(실측 57건) |
| **폭주 억제** | 같은 오경보가 반복될 때 알림 수를 줄이는 것 |
| **셔플 검증** | 테스트 **실행 순서를 섞어** 여러 번 돌려 순서 의존 결함을 찾는 것 |
| **게이트** | 커밋 전에 통과해야 하는 자동 검사(5종) |
| **프로파일** | 현장별 설정 묶음(`deploy/academy/`). 전역 기본값과 다른 값만 담는다 |
| **드리프트** | 프로파일이 전역 기본값에 뒤처져 조용히 어긋나는 것 |
| **F3 · F9 · D3** | 결함·결정 항목 번호. `F`=`SAFETY_REVIEW_REPORT.md`, `D`=`docs/PILOT_DECISIONS.md` |
| **미확인** | ★확인하지 않았다는 뜻. **추측으로 채우지 않는다** |

## 컴퓨터 비전

| 용어 | 뜻 |
|---|---|
| **RTSP** | IP 카메라가 영상을 흘려보내는 표준 프로토콜 |
| **검출(detection)** | 한 장의 사진에서 물체를 찾아 **박스 + 라벨 + 확신도**를 내는 것 |
| **추적(tracking)** | 프레임 사이에서 **같은 물체에 같은 번호(tid)** 를 유지하는 것 |
| **RF-DETR** | 트랜스포머 계열 검출 모델. **Apache-2.0**(상용 자유) |
| **YOLO(ultralytics)** | 널리 쓰이는 검출 모델. ⚠**AGPL-3.0** — 납품 시 소스공개 의무 |
| **ByteTrack** | 추적 알고리즘. 낮은 확신도 박스도 2단계로 붙여 끊김을 줄인다 |
| **COCO** | 80종 일반 물체 공개 데이터셋. person 모델이 여기서 사전학습됐다 |
| **LOCO · D-Fire · css_safety** | 각각 물류(지게차)·화재/연기·건설안전 공개 데이터셋 |
| **conf(confidence)** | 검출 확신도 0~1. **임계(threshold)** 아래는 버린다(현재 PPE 0.35) |
| **NMS** | 같은 물체에 겹쳐 나온 박스를 하나만 남기는 후처리 |
| **IoU** | 두 박스가 얼마나 겹치는가(교집합÷합집합). 0~1 |
| **mAP@50** | 검출 성능 종합 지표. IoU 0.5 기준 |
| **재현율(recall)** | 실제로 있는 것 중 **몇 %를 찾았나**. 낮으면 **놓친다(미탐)** |
| **정밀도(precision)** | 찾았다고 한 것 중 **몇 %가 진짜인가**. 낮으면 **헛울린다(오탐)** |
| **PPE** | 개인보호구(Personal Protective Equipment) — 안전모·조끼·마스크 |
| **RTMPose** | 자세(관절) 추정 모델. 근골격 위험 지표에 쓴다 |

## 판정·알림 계층

| 용어 | 뜻 |
|---|---|
| **파생 신호** | 검출 결과에서 규칙이 쓰기 좋게 뽑아낸 참/거짓(예: `ppe_missing`) |
| **히스테리시스** | **연속 N프레임** 참이어야 발화. 한 프레임 깜빡임을 막는다(현재 3) |
| **디바운스** | 상태가 **일정 시간 유지**돼야 확정. 구역 침입 1.0초 · 근접 0.4초 |
| **쿨다운** | 한 번 울린 뒤 **일정 시간 다시 안 울림** |
| **백오프** | 반복될수록 침묵 시간을 **배로 늘리는 것**(300s → ×2 → 3600s 상한) |
| **게이트(alert_gate)** | 쿨다운·백오프를 적용해 "이번 건을 보낼지" 정하는 곳 |
| **발화(fired)** | 규칙이 위험이라고 판정한 것. 알림 전송과는 **다르다**(게이트를 거친다) |
| **degraded** | `/health`가 "돌긴 하는데 성한 상태는 아니다"라고 알리는 상태 |
| **소크(soak)** | 장시간(24시간) 연속 가동 시험. 메모리 누수·지연 누적을 본다 |

## 통계

| 용어 | 뜻 |
|---|---|
| **표본(sample)** | 측정에 쓴 데이터 개수. ★이게 없으면 수치를 믿을 수 없다 |
| **층화 표본** | 구간별로 골고루 뽑은 표본. 전체 분포를 그대로 대표하지 **않는다** |
| **군집(cluster)** | 서로 관련된 관측의 묶음. 여기서는 **장면 1개 = 군집 1개** |
| **독립이 아니다** | 0.5초 간격 프레임은 같은 사람이 연속으로 잡혀 서로 관련돼 있다.<br>→ 그래서 **신뢰구간을 붙이지 않는다** |
| **신뢰구간(CI)** | 참값이 있을 만한 범위. ★독립이 아니면 실제보다 **좁게 나와 과신**을 부른다 |
| **부트스트랩** | 표본을 다시 뽑아 분포를 만드는 방법. 군집이 8개뿐이면 불안정하다 |
| **반사실 재현** | "그 기능을 껐다면 어땠을까"를 기록으로 다시 돌려보는 것 |

## 개발·운영

| 용어 | 뜻 |
|---|---|
| **ruff** | 파이썬 린터(코드 스타일·오류 검사) |
| **mypy** | 파이썬 타입 검사기. 여기서는 **19파일 화이트리스트만** 검사 |
| **OpenAPI 차분** | HTTP 엔드포인트 목록이 바뀌지 않았는지 대조(현재 106개) |
| **CI** | 코드를 올릴 때 자동으로 검사를 돌리는 것(GitHub Actions) |
| **커버리지** | 테스트가 코드의 몇 %를 실행하는가. ★**이 프로젝트는 측정한 적 없다** |
| **worktree** | 한 저장소를 여러 폴더로 동시에 여는 git 기능. 세션 격리에 쓴다 |
| **BitLocker / EFS** | Windows 볼륨/파일 암호화. **Pro 이상**에서만 된다 |
| **KFM** | Known Folder Move. 바탕화면이 통째로 OneDrive로 동기화되는 설정 |
| **NFC / NFD** | 유니코드 정규화 방식. 한글 파일명이 두 방식으로 섞이면 **대조가 어긋난다** |
| **NSSM** | Windows 서비스 등록 도구 |
| **LabelMe / CVAT** | 라벨링(정답지 작성) 도구 |
