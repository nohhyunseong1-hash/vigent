# 03. 설계 결정과 **버린 대안**

> 이 문서가 이 묶음에서 가장 중요하다.
> "왜 이렇게 했나"보다 **"무엇을 안 했고 왜인가"** 가 사람의 판단력을 보여준다.
>
> ★근거가 된 측정값을 각 항목에 붙였다. **근거 없이 정한 것은 "근거 없음"이라고 썼다.**

## 1. 검출 모델: YOLO → **RF-DETR** 이관

| | |
|---|---|
| **버린 것** | ultralytics YOLO11 (person·PPE·화재·지게차 전부) |
| **채택** | RF-DETR Nano (Apache-2.0) |
| **근거(측정)** | person mAP@50 **YOLO 90.82% → RF-DETR 93.92%** (dev 74장/87인스턴스)<br>출처: `benchmarks/EVAL.md` ·`benchmarks/COVERAGE.md` |
| **★진짜 이유** | 정확도는 부차적이다. **YOLO는 AGPL-3.0**이라 납품 시 소스공개 의무가 생긴다. RF-DETR는 Apache-2.0 |
| **미해결** | ★**지게차만 YOLO로 되돌렸다.** RF-DETR 지게차가 현장에서 재현율 2.8%로 부적격이었다.<br>→ **학원 프로파일에 AGPL이 살아 있다**([05](05_알려진_부채_전량.md)) |

## 3. 알림 억제: 고정 쿨다운 → **적응형 백오프**

| | |
|---|---|
| **버린 것** | 고정 300초 쿨다운 |
| **채택** | 300s → 실패마다 ×2 → 3600s 상한 · 시간당 6건 캡 · **등급 상승은 예외 통과** |
| **★근거(측정)** | 24시간 소크 실데이터 재현:<br>**고정 쿨다운 = 무동작 오경보 221건 중 221건 통과(억제 0.0%)**<br>**적응형 백오프 = 221건 → 24건(억제 89.1%)** · 진짜 경보 4/4 보존<br>출처: `docs/proposal_base_2026-08.md` §표 · `docs/CODE_REVIEW_AZ.md` |
| **왜 고정이 무력한가** | 오경보는 같은 대상이 **계속** 만든다. 300초는 그 주기보다 짧다 |
| **★버리지 못한 위험** | 백오프가 1시간까지 늘면 **그 사이 진짜 사고가 나도 침묵**한다([D3], **미해결**)<br>출처: `docs/PILOT_DECISIONS.md` D3 |

## 7. 마스크·조끼 오탐: 모델 재학습 → **현장 프로파일 설정**

| | |
|---|---|
| **문제** | 보호구를 갖춰 입은 작업자에게 경보가 계속 울린다 |
| **★근거(측정)** | 학원: 보호구 경보 490건 중 **87건이 "마스크 미착용"만**이 방아쇠.<br>그중 **81건이 완전 착용 장면(04·07)에 몰림**<br>고소작업: 착용 영상 47프레임에서 `NO-Safety-Vest` 발화 — **작업자는 하네스를 찼고 조끼는 안 입었다** |
| **버린 것** | 마스크·조끼 검출기 재학습 |
| **★왜 버렸나** | **모델이 틀리지 않았다.** 실제로 마스크를 안 썼고 조끼를 안 입었다.<br>완벽한 검출기도 같은 답을 낸다. **오탐이 아니라 규칙 부적합**이다 |
| **채택** | `ppe.required` 를 **현장 프로파일**로 고른다. 학원 = `[NO-Hardhat, NO-Safety-Vest]` |
| **회귀 검증** | 같은 원자료 재계산: 490 → 403건. **안전모·조끼 경보 손실 0건** |
| **★전역 기본값은 3종 유지** | 실내 분진 현장에서는 마스크가, 도로 인접 작업에서는 조끼가 필수다 |

### 이 결정에서 파생된 안전장치
`ppe.required` 에 **알 수 없는 라벨이 하나라도 섞이면 설정 전체를 무효**로 보고 기본값으로 돌아간다.
→ 처음 구현은 "유효한 것만 골라 쓰기"였는데, 그러면 `['helemt','NO-Safety-Vest']` 오타 하나로
**안전모 경보가 조용히 사라진다.** 커버리지가 줄어드는 유일한 경우에 경고가 가장 약했다.

## 8. 근거 없이 정한 것 (정직하게)

| 항목 | 현재 값 | 상태 |

| 판정 주기 2fps | 2.0 | ★**근거 없음.** "실시간처럼 보이는 최소값"으로 잡았을 뿐 측정 없음 |
| 구역 디바운스 1.0초 | 1.0 | ★근거 없음. 근접 0.4초는 "지게차가 3m 반경을 통과하는 데 1.1초" 계산이 있다 |
| 히스테리시스 3프레임 | 3 | 근거 없이 정했으나 **2026-08-29에 사후 측정**함 → 3→2 완화 가능·1 금지 |
| 위험반경 3m | 3.0 | ★근거 없음. 법령·표준 대조 안 함 |
| 노트북 1대 구성 | — | ★근거 없음. 엣지박스 비교 **미검토** |

> ★이 표를 지우지 않고 남기는 이유: 근거 있는 결정과 없는 결정이 섞여 있으면
> 전부 근거 있는 것처럼 읽힌다. 그게 더 위험하다.
