  ★사다리 영상 실측: 사람 있는 66프레임 중 **33프레임이 임계 미달**,
  **"검출 후보가 아예 없는 프레임은 0개"**(conf 0.05 재실행으로 확인).

## 3. ★이 수치들을 전체 정확도로 쓸 수 없는 이유

| 이유 | 설명 |
|---|---|
| **프레임이 독립이 아니다** | 판정이 0.5초 간격이다. 같은 사람이 연속으로 잡힌다.<br>★그래서 **신뢰구간을 붙이지 않는다.** 이항 CI는 실제보다 좁아 과신을 부른다 |
| **군집이 작다** | 군집(장면) 단위로 묶으면 유효 표본이 **8개**다. 부트스트랩도 불안정하다 |
| **층화 표본이다** | 스틸 120장은 5초 간격 층화 표본이다. 전체 분포를 대표하지 않는다 |
| **정답이 장면 대본 수준** | "이 장면에서는 안전모를 썼다"는 시나리오 설계값이 정답이다.<br>프레임마다 사람이 라벨링한 것이 **아니다** |
| **단일 세션** | 카메라 1대 · 대상 1명 · 주간·맑음 · 54분 |

### 실제로 있었던 표기 사고
v1.2 초안에서 "17.8% [1.2, 44.2]" 처럼 구간을 병기했다가 **뺐다**.
군집 8개로는 구간 자체가 불안정하고, 구간을 붙이면 읽는 사람이 **가운뎃값에 닻을 내린다.**
→ 지금은 **관측값만** 쓴다: *"이 표본 490건 중 87건이 마스크 단독 원인이었다."*
