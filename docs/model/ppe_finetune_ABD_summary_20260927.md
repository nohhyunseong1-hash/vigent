## 2. 판단 근거 (측정한 것만)

1. **held-out**: A·B·D 의 NO-Hardhat 재현율은 전부 v1 구간 안이고, 4클래스 AP50 도 80.2~81.3 으로 같다. 507 을 넣든(A·B) 빼든(D) 차이가 없다 → **507 은 held-out 4클래스 성능을 올리지 못한다** [실측 3회].
2. **dev74**: 507 없이 CSS 만으로 v1 을 이어 학습한 D 도 v1 보다 −7.8 %p 낮다(구간 겹침 없음: D [48.1, 60.8] vs v1 [55.9, 68.3] 경계 근접). A·B(−9.5/−10.8)와 D 의 차이는 구간 안 → 하락의 **주된 원인은 507 이 아니라 "v1 이어 학습 레시피"** 다. 후보 원인 [추정]: (a) 슬롯 의미 충돌(person·Hardhat·Safety-Vest 가 v1 의 Hardhat·Mask·NO-Mask 슬롯 위에서 학습, A 문서 첫 줄 단서) (b) lr 1e-4 로 10 epoch — v1 이 dev74 에서 갖고 있던 일반화가 CSS 재학습으로 깎임(v1 은 Colab 에서 다른 스케줄로 학습됨, provenance §2). 어느 쪽인지는 **미확인**(실험 안 함).
3. **정지 규칙** 적용: "D 까지 보고도 held-out NO-Hardhat R 이 v1 구간을 못 벗어나면 중단·v1 유지" — 발동. **v1 유지**, 재학습 산출물 A·B·D 는 어디에도 배포하지 않는다.
4. 목표 재확인: 목표는 현장 맞춤이 아니라 AI Hub 로 held-out 4클래스 성능을 올리는 것이었다. 507 로는 불가함이 실측됐고, 네 클래스가 모두 라벨된 AI Hub 데이터는 조회에서 확인되지 않았다(`aihub_ppe_dataset_candidates_20260927.md` — 163 확인 대상·71770 안전모 전용).
