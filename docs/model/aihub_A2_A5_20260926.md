**Hardhat 14.6% 의 진단 [실측]**: 검출기는 720장 중 **719장에서 안전모 박스 1개**를 냈고, 그 박스는 사람 박스 **상단에 정확히 붙어**(오프셋 중앙 0.00) 높이는 사람의 **0.21**(p10 0.14 · p90 0.28)이다. 즉 검출은 됐는데 우리가 만든 파생 GT(상단 17%·정사각·수평 중앙)와 **IoU 중앙 0.18**(≥0.5 는 106/719)이라 매칭이 안 된 것 — 머리가 사람 박스 수평 중앙에 있지 않은 자세(웅크림·측면)가 많다. → **파생 Hardhat 은 평가 GT 로 부적합**하고, 같은 이유로 **학습 라벨로도 위험**하다(잘못된 박스를 정답으로 가르침). 결론: 507 은 **NO-Hardhat 보강 전용**으로 두고, Hardhat 양성은 (a) 진짜 머리 라벨(CSS·현장 정답지) 또는 (b) 사람 박스+검출기 박스 교차 확인을 거친 별도 라벨링 작업으로만 만든다. A-2 의 "WO-01 상단 17%→Hardhat" 옵션은 **기본 OFF 유지 + 비권장** 으로 강등.
