## 3. 정직하게 적는 단서

1. **스모크 1회**다. 시드 1개·epoch 10·train 5,000장. 재현성(시드 바꿔 2회 이상)·전체 8,789장 학습·더 긴 epoch 은 안 했다.
2. **같은 데이터셋 안 검증**이다(AI Hub 510 의 다른 장소). 현장 CCTV(원거리·소인물·야간)와 다르다. 학원 집합이 유일한 현장 근사인데 참고 등급이다.
3. **음성이 얇다**: 510 val 지게차 없음 101장 → 오탐률 0 이어도 상한 3.7 %. 507 음성 2,000장은 도메인이 다르고 1.4 % [0.9, 2.0] 이라 목표 1 % 를 **그 자체로는 넘는다**. 결론 전에 510 계열 음성(VS_03·VS_07 외 공정)을 늘려 다시 잰다.
4. **운용 파이프라인 미검증**: 이 표는 `predict`(res 384, conf 0.5, IoU 0.5) 값이다. 추적·히스테리시스·근접 규칙을 거친 값, 4채널 지연·VRAM 영향(`bench_4ch`)은 별도.
5. 1차 실행은 검증 후처리(torchmetrics COCO 변환)에서 2시간 정체돼 중단했고, 그 epoch 0 결과는 근거로 쓰지 않는다(`stall_pyspy_1st_run.txt`).
6. 학원 참고 열의 boda_ax 97.7 % 는 대본 기준·YOLO 값이라 이 표의 후(fk_510_smoke) 96.4 % 와 **같은 잣대가 아니다**(후 행은 "그 YOLO 박스와 겹치는가").
