## 2. 읽는 법 (측정한 것만)

1. **A 와 B 의 차이는 전부 신뢰구간 안**이다(NO-Hardhat 65.6 ↔ 62.5, NO-SV 82.2 ↔ 80.7, dev74 52.8 ↔ 51.5). → **조끼 준라벨로 507 의 라벨 누락을 메워도 결과는 움직이지 않았다.** "라벨 누락 음성" 자체는 실측(89.8 %)된 사실이지만, 그것이 A 하락의 원인이라는 가설은 **B 로 지지되지 않는다.**
2. 준라벨 품질 문제인지도 이것으로는 판단할 수 없다 — 준라벨을 **넣은** 쪽(B)이 넣지 않은 쪽(A)과 같았을 뿐, 준라벨을 **뺀** 대조군은 아직 없다.
3. A·B 공통으로 남는 사실: 507(+준라벨)을 v1 에 이어 학습하면 **dev74 미착용 재현율이 ≈10 %p 떨어지고 held-out 은 제자리**다. 즉 지금 조합의 507 데이터(또는 이어 학습 설정 자체)가 현장 사고영상 쪽 일반화를 깎는다 [실측] — 이유는 미확인.
4. 학습 중 검증(CSS 63 + 507 200)의 EMA mAP50 은 0.82~0.85 로 A(507 위주 800, 0.87)보다 낮게 나왔다 — 검증셋 구성 차이이지 모델 차이가 아니다(held-out 은 같은 수준).
