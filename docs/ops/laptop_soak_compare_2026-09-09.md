## 5. F-34 — 노트북 소크 4회의 경보 지표가 전부 무효인 이유

`ValueError: not enough values to unpack (expected 4, got 3)`. 포즈 스레드가 낸 3-튜플을 메인 루프가 4-튜플로
언패킹해 터진다.

**예외가 잡히는 위치는 프레임 루프 단위다**(개발기 HEAD 코드 기준, `ast` 로 확인). `worker._process_frame`
(977~1151)의 `try` 가 985~1151 로 함수 본문 거의 전체(986~1138)를 감싸고 handler 는 1139~1151 하나뿐이며,
**포즈 이벤트 단위 try 는 없다.** 따라서 1069 줄에서 터지면 1070~1138 이 통째로 건너뛰어진다 —
쿨다운 갱신, 이벤트 기록, 증거 JPEG 인코딩·디스크 쓰기, 알림 적재가 **그 프레임에서 전부 실행되지 않는다.**
