## 2. 무엇을 라벨링하는가

### 2-1. 클래스 (8종 — 현 모델 출력과 같게)

| 클래스 | 박스 범위 규칙 |
|---|---|
| `person` | **보이는 신체 전체.** 가려진 부분은 **포함하지 않는다**(캐빈 기둥에 가리면 보이는 부분만). 화면 밖으로 나간 부분도 포함하지 않는다 |
| `forklift` | 차체 전체. **포크·마스트 포함**, 들어올린 화물은 제외 |
| `Hardhat` / `NO-Hardhat` | **머리 영역**(정수리~턱). 착용이면 `Hardhat`, 맨머리면 `NO-Hardhat`. 머리가 안 보이면 **아무것도 달지 않는다** |
| `Safety-Vest` / `NO-Safety-Vest` | **몸통**(어깨~허리). 형광 조끼 착용이면 `Safety-Vest` |
| `Mask` / `NO-Mask` | **얼굴 하단**(코~턱). 얼굴이 안 보이면 달지 않는다 |

### 2-2. ★판단이 갈리는 경우 — 미리 정해 둔다
라벨러가 그때그때 정하면 정답지가 흔들린다. 아래는 **규칙으로 고정**한다.

| 상황 | 규칙 |
|---|---|
| 사람이 캐빈 안에 있고 상체만 보임 | `person` = 보이는 상체. 머리 보이면 안전모 라벨도 단다 |
| 사람이 화면 가장자리에 절반만 걸침 | 보이는 부분에 `person`. **너비·높이가 화면의 2% 미만이면 라벨하지 않는다** |
| 안전대(하네스)만 착용 | **`NO-Safety-Vest`** (하네스는 클래스가 없다 — `docs/detection_limits.md` [C]) |
| 안전모를 손에 들고 있음 | **`NO-Hardhat`** (머리에 쓴 것만 착용으로 본다) |
| 뒤통수만 보임 | 안전모 판단 가능 → 라벨. 마스크는 **판단 불가 → 라벨하지 않는다** |
| 흐려서 사람인지 확신이 안 섬 | **`person` 을 달되 `flags.uncertain=true`** 로 표시. 집계에서 따로 뺄 수 있게 |

★**"판단 불가"를 억지로 채우지 않는다.** 비워 둔 것과 "없다"고 단정한 것은 다르다.

## 5. ★다섯 건의 판정 기준 — 라벨링 **전에** 선언한다

측정한 뒤에 기준을 정하면 원하는 결론이 나온다. 현장 방문 때 D1·D5 를 미리 선언해
사후 합리화를 막았던 것과 같은 방식이다.

| # | 항목 | 정답지로 무엇을 계산하나 | 미리 정한 판정 기준 |
|---|---|---|---|
| ① | 지게차 RF-DETR ↔ YOLO | 두 모델의 **box mAP@50**(같은 표본) | RF-DETR 이 **+3%p 이상** 높으면 교체 · **±3%p 이내면 현행 유지**(교체 비용이 이득보다 크다) · 낮으면 유지 |
| ② | 검출 임계값 | conf 를 0.25~0.55 로 훑어 **재현율·정밀도 곡선** | 현 0.35 대비 **재현율 +5%p 이상이면서 정밀도 하락 3%p 이내**인 값이 있으면 채택. 없으면 0.35 유지 |
| ③ | 히스테리시스(현 3프레임) | 1·2·3·4프레임에서 **미탐 건수 ↔ 오탐 건수** | 3→2 로 줄일 때 **미탐 감소 ≥ 오탐 증가**면 완화 · 아니면 3 유지. ★오탐이 2배 이상 늘면 **무조건 3 유지** |
| ④ | 교차검증 순서(고아 PPE 57건) | 순서를 바꿨을 때 **놓치는 미착용 경보 수** | 미착용 경보가 **한 건이라도 사라지면 현행 유지**. 0건일 때만 이동 |
| ⑤ | 캐빈 안전모 재학습 | 캐빈 구간 **안전모 판정 정확도** | 라벨 데이터가 **캐빈 구간 60프레임 이상** 모이면 재학습 착수. 재학습 후 캐빈 정확도가 **67.9% → 80% 이상**이면 채택, **지상 98.4% 가 2%p 넘게 떨어지면 기각** |

★**④의 기준이 유독 엄격한 이유**: 지금 person 인식률이 38~42% 라 고아 PPE 가
그 구멍을 메우고 있다. 안전한 쪽(과경보)에서 위험한 쪽(미탐)으로 가는 변경이므로
"조금 나빠져도 괜찮다"를 허용하지 않는다. 근거: `audit/ppe_box_geometry_2026-08-29.md`.
