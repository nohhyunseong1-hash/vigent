## 제안 문구

```markdown
11. **"완료"라고 말하기 전에 결과물이 실제로 있는지 확인한다.**
    함수가 예외를 던지지 않은 것은 **일이 됐다는 증거가 아니다.** 파일을 썼다면 파일이
    있는지·크기가 0이 아닌지, 호출을 걸었다면 상대가 받았는지, 목록을 처리했다면 처리한
    개수가 기대와 같은지를 **같은 실행 안에서 확인**하고, 다르면 성공이 아니라 **실패로
    보고**한다.
    - 특히 **"0건 처리"는 기본적으로 실패로 의심한다.** 대상이 0개여서 0건인지,
      찾지 못해서 0건인지는 전혀 다른 일이다. 구분되지 않으면 그렇게 말한다.
    - 검증 비용이 큰 경우에도 **최소한 개수는 센다.** 세지 않은 것을 "완료"라 하지 않는다.
    - 이 규칙은 규칙 7(할루시네이션 금지)의 실행판이다. 확인하지 않은 성공을
      성공이라 말하는 것은 지어낸 사실을 말하는 것과 같다.
```

## 근거 — 같은 병의 다섯 번째다

| # | 사례 | 무엇이 "성공"으로 보고됐나 | 실제 |
|---|---|---|---|
| 1 | **dispatcher 호출부 0개** | 기능이 구현돼 있다 | 구현은 있었으나 **아무도 부르지 않았다** — 코드가 존재하는 것과 동작하는 것을 구분하지 않았다 |
| 2 | **삭제 스크립트 미호출** | 자동 파기가 동작한다 | 스크립트는 있었으나 **호출 경로가 없었다** |
| 3 | **카메라 0대 전부통과** | 헬스체크 통과 | 검사 대상이 **0대**라 통과였다. "이상 없음"과 "볼 것이 없음"을 구분하지 않았다 |
| 4 | **`alert_queue.stop()` 무동작** | 정지 완료 | 플래그만 세우고 **join 하지 않아** 스레드가 계속 돌았다. 반환값이 없으니 성공처럼 보였다 |
| 5 | **`cv2.imwrite` 한글 경로** | "34장 저장 완료" | `imwrite` 가 예외 없이 `False` 를 돌려주고 **파일은 0개**였다. 개수는 메모리 리스트에서 세고 있었다 |

### 공통 구조
다섯 건 모두 **"호출했다"를 "됐다"로 바꿔치기**했다.
예외가 없으면 성공이라고 가정했고, 결과물을 **한 번도 다시 보지 않았다.**

- 1·2 는 **호출 자체가 없었는데** 코드가 있다는 이유로 완료로 봤다.
- 3 은 **대상이 없었는데** 통과로 봤다.
- 4·5 는 **함수가 조용히 실패**했는데 반환값을 안 봤다.

### 왜 규칙 7로는 부족한가
규칙 7은 "측정하지 않은 수치를 지어내지 마라"이다. 위 다섯 건은 **수치를 지어낸 게 아니라
'완료'라는 상태를 지어낸 것**이다. 같은 병인데 규칙 문구가 수치에만 걸려 있어
매번 빠져나갔다. 그래서 **결과물 확인**을 따로 규칙으로 세운다.

## 이미 적용해 본 결과 (이 규칙이 실제로 작동하는가)

`scripts/extract_rule_frames.py` 에 확인 절차를 넣었다:

```python
def _imwrite(path, img, q=90):
    ok, buf = cv2.imencode(".jpg", img, [cv2.IMWRITE_JPEG_QUALITY, q])
    if not ok:
        raise RuntimeError(f"JPEG 인코딩 실패: {path}")
    path.write_bytes(buf.tobytes())
    if not path.exists() or path.stat().st_size == 0:   # ★쓴 것을 다시 본다
        raise RuntimeError(f"파일이 쓰이지 않았다: {path}")
```
```python
made = len(list(out.glob("f*.jpg")))      # ★메모리가 아니라 디스크를 센다
if made != len(tiles):
    print(f"  ❌ 쓰기 누락: 만든 {len(tiles)} vs 디스크 {made}")
    return 1
```

같은 실행에서 **"34프레임(디스크 확인)"** 이라고 출력이 바뀌었다.
확인이 없었다면 이번에도 0장을 34장이라고 보고했을 것이다.

## 적용 범위 제안
- **파일 생성**: 존재·크기 확인. 여러 개면 개수 대조.
- **외부 전송**: 응답 코드·수신 확인. "예외 없음"으로 갈음하지 않는다.
- **일괄 처리**: 입력 개수 ↔ 처리 개수 ↔ 출력 개수를 맞춰 본다.
- **정지·해제**: 실제로 멈췄는지 확인(스레드 join, 핸들 해제).
- **검사·게이트**: 검사 대상이 **0개**면 통과가 아니라 **"검사하지 못함"** 으로 보고한다.
