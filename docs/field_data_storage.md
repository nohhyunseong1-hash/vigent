## 1. 문제의 구조

이 PC 는 **바탕화면 자체가 OneDrive 로 리디렉션**돼 있다(KFM, Known Folder Move).

| 확인 항목 | 값 |
|---|---|
| `OneDrive` 환경변수 | `C:\Users\shgus\OneDrive` |
| 레지스트리 `User Shell Folders\Desktop` | `C:\Users\shgus\OneDrive\바탕 화면` |
| OneDrive 프로세스 | 가동 중 |
| 폴더별 제외(selective sync) | 설정 없음 |

**→ 바탕화면에 놓는 모든 것이 자동으로 클라우드에 올라간다.**
현장 촬영본을 "일단 바탕화면에" 두는 습관이 곧 개인정보 업로드가 된다.

★**클라우드 사본은 로컬 삭제로 사라지지 않는다** — OneDrive 휴지통(기본 30일)과
버전 기록에 남는다. 옮긴 뒤 웹에서 별도로 비워야 한다.

## 3. 반출 경로를 한 곳으로 — 이미 지켜진 규칙

현장 자료를 저장소에 넣을 때의 기준은 **이미 `.gitignore` 에 2중으로** 박혀 있다.

```gitignore
runs/*                      # ① 통째로 제외
!runs/field_*/              # ② 현장 폴더만 되살리되…
!runs/field_*/**/*.jsonl    #    텍스트만
!runs/field_*/**/*.md
!runs/field_*/**/*.json
runs/field_*/**/*.jpg       # ③ ★이미지·영상은 다시 제외
runs/field_*/**/*.png
runs/field_*/**/*.mp4
data/evidence/
```

**이 규칙은 실제로 작동했다** — 2026-08-27 현장 이미지·영상은 **한 번도 커밋되지 않았다**
(전 브랜치·전 이력 검색으로 확인). 구조를 바꿀 필요는 없고, **원본을 두는 위치**만 정하면 된다.
