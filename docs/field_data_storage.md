## 1. 문제의 구조

이 PC 는 **바탕화면 자체가 OneDrive 로 리디렉션**돼 있다(KFM, Known Folder Move).

| 확인 항목 | 값 |
|---|---|
| `OneDrive` 환경변수 | `C:\Users\shgus\OneDrive` |
| 레지스트리 `User Shell Folders\Desktop` | `C:\Users\shgus\OneDrive\바탕 화면` |
| OneDrive 프로세스 | 가동 중 |
| 폴더별 제외(selective sync) | 설정 없음 |

**→ 바탕화면에 놓는 모든 것이 자동으로 클라우드에 올라간다.**
현장 촬영본을 "일단 바탕화면에" 두는 습관이 곧 개인정보 업로드가 된다.

★**클라우드 사본은 로컬 삭제로 사라지지 않는다** — OneDrive 휴지통(기본 30일)과

## 6. ★클라우드 사본 제거 — 사용자 수동 절차 (남은 작업)

**로컬에서 지운 파일은 OneDrive 웹에 그대로 남아 있다.** 아래는 사람이 브라우저에서 해야 한다
(로그인이 필요해 내가 대신 할 수 없다).

### 6-1. 휴지통 비우기 (필수)
1. https://onedrive.live.com 접속 → 로그인
2. 왼쪽 메뉴 **휴지통(Recycle bin)**
3. `삼영중장비 테스트` 관련 항목 선택 → **영구 삭제 / 휴지통 비우기**
4. ★**휴지통이 두 단계다** — 휴지통 화면에서
   **"2단계 휴지통(Second-stage recycle bin)"** 링크를 눌러 **거기서도 비운다.**
   1단계에서 지운 것이 2단계로 다시 들어가기 때문에, 여기를 빼먹으면 안 지워진 것과 같다.

> 보존 기간: 개인 OneDrive 기본 **30일**. 비우지 않으면 그때까지 클라우드에 남는다.

### 6-2. 버전 기록
파일 자체가 영구 삭제되면 버전 기록도 함께 사라진다. **6-1 을 마치면 이 항목은 자동 해결**된다.
따로 보고 싶으면 웹에서 파일 우클릭 → **버전 기록**.

### 6-3. 반영 확인 (3가지)
1. 작업 표시줄 OneDrive 아이콘 → **"최신 상태"** 인지 확인
2. 웹에서 `바탕 화면` 폴더를 열어 **`삼영중장비 테스트` 가 없는지** 눈으로 확인
3. 웹 검색창에 `삼영중장비` 입력 → **결과 0건**인지 확인

### 6-4. 완료 보고
위 3가지가 확인되면 이 항목이 끝난다. 결과를 알려주면 이 문서에 완료로 적는다.
★**현재 상태는 "로컬 이동 완료 · 클라우드 미확인"이다.** 클라우드까지 확인해야 종료다.
