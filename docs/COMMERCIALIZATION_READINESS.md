# VIGENT 상용화 준비도 점검 (파일럿 관점)

> 작성: 2026-07-19 · 대상: safety 테마 비전 검출·에이전트 시스템.
> 목적: **"실제 고객 현장 파일럿"까지의 거리**를 정직하게(규칙 7) 파악. 잘 된 것 나열이 아니라 **갭 중심**.
> 근거: 모든 등급·수치는 커밋/소크리포트/FINDINGS/실측에 링크. **미검증은 "미검증"으로, 추정은 "추정"으로** 표기.
> ⚠ 안전 경계(불변): 비전 ML 은 확률적 → **인증 안전기능(안전 PLC·Type4 방호장치)을 대체하지 않는 보조·감시 계층**(CLAUDE.md).

## 0. 한 줄 결론 (낙관 금지)

**현재 필드-검증(A등급) 기능은 사실상 0개다.** 실영상 검증은 **크레인재해 46초 1건**이 전부이고, 그 1건은 오히려 **핵심 갭(광역 CCTV 해상도로 낙상/소형작업자 자동검출 불가)**을 드러냈다. 대부분 기능은 **B(구현+테스트, 공개셋 정확도)** 또는 **C(구현만)**이며, forklift/proximity 는 **D(비활성)**. 안정성은 **1시간 합성 소크만 합격**(24h·실카메라 미검증)이고 **동시부하 네이티브 크래시(F-14)**가 미해결이다. → **"기능 완성"이 아니라 "가장 검증된 1~2개로 최소 파일럿" 전략이 유일하게 정직한 경로**(§3).

## 1. 기능 인벤토리 — 성숙도 등급

등급: **A** 실영상 검증됨 / **B** 구현+테스트만(실영상 미검증) / **C** 구현만 / **D** 미배선·보류

| 기능 | 등급 | 근거 | 알려진 한계 |
|---|---|---|---|
| **guard.detect (person 코어)** | B | 웹캠 실측 person recall 강건(F-9: 100%, 좌표검증), 엔드포인트 스모크(P2-14) | **정식 현장 미검증**. 광역 CCTV 소형작업자 recall 낮음(B8: 기본임계서 0%). **라이브 추적(_track) 미검증**(FINDINGS F-8 백로그). (공개셋 person mAP 수치는 이 문서에서 미재확인) |
| **zone_intrusion** | B→C | 로직 유닛/스모크 테스트, B9 구역-타일로 소형작업자 recall 0→89~95% **실영상 실측** | 기본검출은 소형작업자 놓침. **B9 타일은 기본 off + 현장 오탐 미확인**. 타일 시 핫패스 +415ms/f(CPU) |
| **PPE (착용/미착용)** | B | 공개셋 실측: 착용 R67~76(Hardhat 76·Mask 75·Vest 67), **미착용 NO-Hardhat R56.1(안전모 미착용 ≈44% 놓침, 최대 약점)** | **현장 미검증**. 미착용 재학습 필요(F-9). conf 하향은 오탐 트레이드오프 |
| **fire_smoke (화재/연기)** | B | 공개셋 D-Fire mAP@50 **80.13%**(게이트 통과, FINDINGS) | **현장 미검증**. 실현장 조명·연기 조건 미측정 |
| **proximity (협착)** | D | 로직 존재, `_derive` 배선 | **배포 forklift 검출기 비활성(F-7/F-9 오탐)** → 차량 근처 판정 사실상 무동작. (PoC 로 mAP 8.83→58.62% 개선 실증했으나 **full 재학습·배포 복원 전까지 비활성**) |
| **crowd (밀집)** | C | person_count 임계 | 현장 미검증. person 검출 정확도에 종속 |
| **motion (무동작·급이동)** | C | MotionTracker 구현 | 현장 미검증. 합성 외 실측 없음 |
| **낙상 (FallTracker)** | C | 다중단서+모션 로직, 유닛테스트(합성 obs) | **B8 실측: 광역 CCTV 쓰러진 작업자 검출 recall 0%**(자세/pose 불가). 근접·고해상 카메라 전엔 실효 없음 |
| **rig_monitor (줄걸이)** | 로직 **B** / 배선 **D** | 상태기계 (b)낙상 경보 **실영상 타이밍 검증**(B4: 사고 t=38→ALARM t=38.21s, 수동 obs) | **하드 fall-alarm 라이브 배선 불가 확정(B8)** — 입력(fall obs)을 이 카메라로 못 만듦. (a)하물높이는 검출기 부재로 미검증 |
| **incident (재해분석)** | C | VLM 기반 사후분석, 구현 | 로컬 MLX VLM 느림(6~8s/건, Apple전용). 클라우드는 opt-in(F-12). 현장 미검증 |
| **TBM 회의록/위험성평가서** | C | 생성기 구현(라우트 존재), Scribe+Copilot | 위험성평가서만 실동작, TBM/관리체계/아차사고 생성기는 부분·백로그(AGENT_STATUS). 현장 미검증 |
| **recognition (출입로그)** | C | 로그 기록/조회 구현 | 얼굴인식 실동작·현장 미검증. 개인정보 처리 미비(§2 보안) |
| **dispatch (보조 방호신호)** | B | 구현+테스트(test_machine_guard `/dispatch/relay`), 웹훅 화이트리스트 fail-closed | **보조 신호일 뿐 인증 방호장치 대체 아님**. 실제 알림 채널 현장 연동 미검증 |
| **VLM 계열(scene/behavior)** | C | 로컬 MLX + 클라우드 opt-in | 느림·Apple전용(로컬). 현장 미검증. 중국어 누출 가드는 있음 |
| **법령 근거 인용(Copilot/RAG)** | C | 화이트리스트 게이트 실동작(F-11) | 폐쇄망 코퍼스 기반. 인용 정확도 현장 미검증 |

**요약**: **A 0개** · B 5개(코어·zone·PPE·fire_smoke·dispatch — 전부 공개셋/테스트 수준이지 현장 아님) · C 다수 · D 2개(proximity·rig 배선). **낙상은 이 카메라론 C(사실상 미작동)**.

## 2. 파일럿 배포 블로커 (심각도순)

### 🔴 심각(파일럿 전 필수)

1. **실영상 검증이 사실상 없음(1건)** — 필드 검증 데이터 = **크레인재해 46초 1건**뿐. 그마저 낙상 자동검출 실패를 드러냄. **어떤 기능도 "현장에서 이만큼 잡는다"는 실측 근거가 없다.** 파일럿 = 그 자체가 첫 실영상 검증이 되는 위험.
2. **동시부하 네이티브 크래시(F-14) 미해결** — 브라우저 2연결 + 무거운 다중추론 중 프로세스 종료(exit 133). `_DETECT_LOCK`·`prefer_mps=False` 로 **완화**했으나 **원인 미확정**. 24시간 무인 감시에서 크래시는 치명(감지 중단). watchdog 재시작은 있으나 크래시 빈도·조건 미측정.
3. **24시간·실카메라 연속구동 미검증** — 소크는 **1시간·합성 소스**만 합격(real1h: 합성 2워커, guard=real). **실 RTSP 카메라 24h·다중대수는 미측정**. realsmoke(40s)는 **불합격** 이력. 메모리 최대 스파이크 919MB 관측(real1h).
4. **GPU 인프라 부재** — RF-DETR 구역-타일 **415ms/frame(CPU)**. 다중카메라 실시간엔 GPU 필수(현재 개발=Apple MPS, MPS는 다모델 동시추론 불안정 이력). 프로덕션 GPU 서버 스펙·비용 미산정(추정 필요).

### 🟠 중대(파일럿 품질/신뢰)

5. **핵심 검출 약점** — NO-Hardhat recall ≈56%(미착용 절반 놓침), forklift 비활성(협착 무동작), 소형작업자 zone recall 기본 0%. → **"안전 감시"의 대표 시나리오(미착용·협착·침입)가 현장 조건에서 얼마나 잡히는지 미검증**.
6. **라이브 추적(_track) 미검증(F-8 백로그)** — ID 스위치·유령추적 등 추적 고유 실패가 낱장 벤치로 안 잡힘. 인원 카운트·침입 지속판정에 영향.
7. **카메라 요구 스펙 미충족(광역 CCTV)** — 자세/낙상 판별엔 작업자 **≥120px** 필요(B8), 현재 광역 CCTV는 26~64px. **rig/낙상 파일럿은 근접 카메라 없이는 불가.**

### 🟡 보안·규정

8. **인증 체계는 최소 수준** — 토큰 `hmac.compare_digest`(P0-3)·클라우드 VLM opt-in(F-12)·path traversal 차단(P0-1)은 되어 있음. **그러나**: 무토큰 로컬모드 DNS-rebinding(Host 미검증, CODE_REVIEW §3.3), 파일럿 네트워크 노출 시 `VIGENT_API_TOKEN` 상시화가 **규칙으로만 있고 강제 아님**. TLS/역프록시 배포 가이드 미비.
9. **영상 개인정보 처리 미비(safety)** — 증거 프레임은 로컬 저장이나 [data_engine.py:12](../vigent-core/data_engine.py#L12) 가 **"얼굴 비식별화·암호화는 상용 단계 과제"**라 명시(=미구현). safety 현장 영상의 **작업자 식별·보관기간·동의·노사협의** 방침이 코드·문서에 없음 → 개인정보보호법·근로기준법 대상(파일럿 전 필수).
10. **산업안전 규제 관점 미정리** — 중대재해처벌법·산안법 하에서 VIGENT 는 **보조 신호**일 뿐 법적 안전조치를 대체하지 못함(경계는 명시됨). 파일럿 계약서에 **"인증 안전기능 대체 아님·오탐/미탐 면책·데이터 소유"** 명문화 필요(법무 검토 = 기술 외 블로커).

### 🟢 데이터

11. **검증용 footage 절대 부족** — B8 재개조건: 어드바이저 검증엔 **낙상 사고영상 ≥10건 + 정상작업 ≥3시간**, 근접카메라 스펙 실측 필요. 현재 1건. **모델 재학습(forklift·PPE 미착용)에도 현장 데이터 필요**(F-7·F-9).

## 3. 파일럿까지의 최단 경로 (최소 파일럿 관점)

**"모든 기능 완성"은 비현실적.** 가장 검증에 가까운 조합으로 **범위를 좁힌 감시 파일럿**을 제안한다.

### 후보 A — "위험구역 침입 경보" 최소 파일럿 (추천)
- **기능 조합**: `zone_intrusion`(구역-타일 B9 활성) + `dispatch`(알림) 만. PPE·협착·낙상·rig 는 **파일럿 범위 제외**(현장 검증 후 단계 추가).
- **왜 가능성 높나**: 침입은 "구역 안에 사람 있냐"의 단순 판정 → 자세/미터보정 불필요(낙상·rig 와 달리). B9 로 소형작업자 recall 도 확보(89~95%, 단 오탐 미확인).
- **반드시 먼저(순서·규모 추정)**:
  1. **현장 카메라 1대 + 실영상 수 시간 확보** → zone-tile **오탐율 실측**(현재 최대 블로커). (추정: 1~2주, 현장 접근 필요)
  2. **GPU 1대 or every-N 튜닝**으로 핫패스 확보(415ms/f→실용). (추정: GPU 조달 or N=4~8 설정, 며칠)
  3. **24h 실카메라 소크** + F-14 완화 검증(동시부하 재현·락 커버리지). (추정: 1주 관측)
  4. **`VIGENT_API_TOKEN` 강제 + TLS/역프록시 + 개인정보 고지·동의 양식**. (추정: 며칠 + 법무)
- **있으면 좋은 것(파일럿엔 불필요)**: PPE 미착용 재학습, forklift 복원, rig 근접카메라.

### 후보 B — "PPE 미착용 게시" (조건부)
- PPE 착용검출 recall 67~76 는 쓸 만하나 **NO-Hardhat 56%(절반 놓침)**이 약점 → "미착용 적발"보다 **"착용 독려 게시"** 수준의 낮은 확신 용도로만. 재학습 전엔 파일럿 부적합(추정).

### ❌ 지금 파일럿 불가
- **낙상·rig_monitor**: 광역 CCTV 해상도 한계(B8). 근접 카메라 + 다중영상 검증 선행.
- **협착(proximity)**: forklift 검출기 비활성(F-7). 재학습 선행.

### 최소 파일럿 전 "필수 vs 있으면 좋은 것"
| 필수(하지 않으면 파일럿 위험) | 있으면 좋은 것(품질↑, 없어도 시작 가능) |
|---|---|
| zone-tile 현장 오탐 실측 | PPE 미착용 재학습 |
| 24h 실카메라 소크 + F-14 검증 | forklift 복원 |
| GPU or every-N 핫패스 | 라이브 추적(_track) 검증 |
| 토큰 강제·TLS·개인정보 동의 | rig 근접카메라 |
| 파일럿 계약 면책·데이터 조항(법무) | 다기능 확장 |
