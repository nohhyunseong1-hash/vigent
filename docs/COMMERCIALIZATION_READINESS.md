## 0. 한 줄 결론 (낙관 금지)

**현재 필드-검증(A등급) 기능은 사실상 0개다.** 실영상 검증은 **크레인재해 46초 1건**이 전부이고, 그 1건은 오히려 **핵심 갭(광역 CCTV 해상도로 낙상/소형작업자 자동검출 불가)**을 드러냈다(낙상 판별 자체는 이후 2026-08 기능 제거 — §1, `docs/P3_BACKLOG.md` PF). 대부분 기능은 **B(구현+테스트, 공개셋 정확도)** 또는 **C(구현만)**이며, forklift/proximity 는 **D(비활성)**. 안정성은 **1시간 합성 소크만 합격**(24h·실카메라 미검증)이고 **동시부하 네이티브 크래시(F-14)**가 미해결이다. → **"기능 완성"이 아니라 "가장 검증된 1~2개로 최소 파일럿" 전략이 유일하게 정직한 경로**(§3).

## 2. 파일럿 배포 블로커 (심각도순)

### 🔴 심각(파일럿 전 필수)

1. **실영상 검증이 사실상 없음(1건)** — 필드 검증 데이터 = **크레인재해 46초 1건**뿐. 그마저 낙상 자동검출 실패를 드러냄. **어떤 기능도 "현장에서 이만큼 잡는다"는 실측 근거가 없다.** 파일럿 = 그 자체가 첫 실영상 검증이 되는 위험.
2. **동시부하 네이티브 크래시(F-14) — ✅ 근본원인 규명·해소(2026-07-20)** — 원인 확정: `mlx-vlm`(MLX)을 FastAPI 워커 스레드에서 실행 시 스레드 teardown 때 네이티브 스레드가 GIL 없이 파이썬 호출 → 즉사(exit 133). 해소: VLM 을 **전용 고정 데몬 스레드**(`rfdetr_service._VLM_RUNNER`)에서만 실행. `tools/stress_concurrent.py`로 재현·수정 실증(미수정=매번 크래시 / 수정=동일부하 2회 생존). 상세: [benchmarks/FINDINGS.md](../benchmarks/FINDINGS.md) F-14.
   - **회피설계(파일럿 안전망, 병기)**: 근본해소와 별개로 운영 기준을 둔다 — ① **머신당 VIGENT 서버 단일 프로세스** 권장(다중 MPS 프로세스는 F-14 를 악화시킨 교란요인. 이 개발 머신엔 `~/Library/LaunchAgents/com.vigent.dev8010.plist`(KeepAlive) 가 8010 서버를 상주시킴 → 파일럿/측정 시 이 dev 에이전트와 별도 서버가 동시에 MPS 를 쓰지 않도록 주의). ② 동시 카메라·동시 VLM 요청은 초기 파일럿에서 보수적으로 상한(예: 카메라 ≤2, VLM 동시 1) → 실측 후 상향. ③ watchdog 자동재기동은 최후 안전망으로 유지(근본해소로 발동 빈도는 0에 수렴 기대, 단 미검증 잔여 위험 대비).
3. **24시간·실카메라 연속구동 미검증** — 소크는 **1시간·합성 소스**만 합격(real1h: 합성 2워커, guard=real). **실 RTSP 카메라 24h·다중대수는 미측정**. realsmoke(40s)는 **불합격** 이력. 메모리 최대 스파이크 919MB 관측(real1h).
4. **GPU 인프라 부재** — RF-DETR 구역-타일 **415ms/frame(CPU)**. 다중카메라 실시간엔 GPU 필수(현재 개발=Apple MPS, MPS는 다모델 동시추론 불안정 이력). 프로덕션 GPU 서버 스펙·비용 미산정(추정 필요).

### 🟠 중대(파일럿 품질/신뢰)

5. **핵심 검출 약점** — NO-Hardhat recall ≈56%(미착용 절반 놓침; ★2026-09-26 갱신 held-out 91장 64.1% [51.8, 74.7]), forklift 비활성(협착 무동작), 소형작업자 zone recall 기본 0%. → **"안전 감시"의 대표 시나리오(미착용·협착·침입)가 현장 조건에서 얼마나 잡히는지 미검증**.
6. **라이브 추적(_track) 미검증(F-8 백로그)** — ID 스위치·유령추적 등 추적 고유 실패가 낱장 벤치로 안 잡힘. 인원 카운트·침입 지속판정에 영향.
7. **카메라 요구 스펙 미충족(광역 CCTV)** — 자세 판별엔 작업자 **≥120px** 필요(B8), 현재 광역 CCTV는 26~64px. **rig 파일럿은 근접 카메라 없이는 불가**(낙상은 2026-08 기능 자체가 제거돼 이 항목의 파일럿 대상에서 빠짐 — 재도입 시 동일 카메라 스펙 필요, PF 참고).

### 🟡 보안·규정

8. **인증 체계 — 🟢 파일럿 기준 대부분 해소(2026-07-21, item3)** — 토큰 `hmac.compare_digest`(P0-3)·클라우드 VLM opt-in(F-12)·path traversal 차단(P0-1)에 더해: **DNS-rebinding 방어**(Host 허용목록, CODE_REVIEW §3.3 해소) + **토큰 강제 옵션**(`VIGENT_REQUIRE_TOKEN=1` → 로컬 무인증 금지) + **TLS 배포 가이드**([TLS_DEPLOYMENT.md](TLS_DEPLOYMENT.md)) 추가. 회귀 테스트 6종(`test_security_gate`). 남은 것: 실배포에서 TLS·역프록시 실구성 검증(현장).
9. **영상 개인정보 — 🟡 정책 초안 작성, 기술통제 일부 미구현** — [PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) 신설(수집항목·법적근거·보관·동의·노사협의·클라우드 위탁·정보주체 권리). **그러나 미구현(정직)**: safety 증거프레임 **얼굴 비식별화·보관기간 자동파기·저장 암호화**는 여전히 미구현([data_engine.py:12](../vigent-core/data_engine.py#L12) 주석대로) → 파일럿 전 §6·§5 구현 + 법무 검토 + 고지·동의·노사협의(§10) 필요.
10. **산업안전 규제 관점 미정리** — 중대재해처벌법·산안법 하에서 VIGENT 는 **보조 신호**일 뿐 법적 안전조치를 대체하지 못함(경계는 명시됨). 파일럿 계약서에 **"인증 안전기능 대체 아님·오탐/미탐 면책·데이터 소유"** 명문화 필요(법무 검토 = 기술 외 블로커).

### 🟢 데이터

11. **검증용 footage 절대 부족** — B8 재개조건: 어드바이저 검증엔 **낙상 사고영상 ≥10건 + 정상작업 ≥3시간**, 근접카메라 스펙 실측 필요. 현재 1건. **모델 재학습(forklift·PPE 미착용)에도 현장 데이터 필요**(F-7·F-9).

## 3. 파일럿까지의 최단 경로 (최소 파일럿 관점)

**"모든 기능 완성"은 비현실적.** 가장 검증에 가까운 조합으로 **범위를 좁힌 감시 파일럿**을 제안한다.

### 후보 A — "위험구역 침입 경보" 최소 파일럿 (추천)
- **기능 조합**: `zone_intrusion`(구역-타일 B9 활성) + `dispatch`(알림) 만. PPE·협착·rig 는 **파일럿 범위 제외**(현장 검증 후 단계 추가). 낙상은 2026-08 기능 자체가 제거돼 대상 아님(PF).
- **왜 가능성 높나**: 침입은 "구역 안에 사람 있냐"의 단순 판정 → 자세/미터보정 불필요(rig 와 달리, 자세 기반 판정이었던 낙상도 이 이유로 어려웠음). B9 로 소형작업자 recall 도 확보(89~95%, 단 오탐 미확인).
- **반드시 먼저(순서·규모 추정)**:
  1. **현장 카메라 1대 + 실영상 수 시간 확보** → zone-tile **오탐율 실측**(현재 최대 블로커). (추정: 1~2주, 현장 접근 필요)
  2. **GPU 1대 or every-N 튜닝**으로 핫패스 확보(415ms/f→실용). (추정: GPU 조달 or N=4~8 설정, 며칠)
  3. **24h 실카메라 소크** + F-14 완화 검증(동시부하 재현·락 커버리지). (추정: 1주 관측)
  4. **`VIGENT_API_TOKEN` 강제 + TLS/역프록시 + 개인정보 고지·동의 양식**. (추정: 며칠 + 법무)
- **있으면 좋은 것(파일럿엔 불필요)**: PPE 미착용 재학습, forklift 복원, rig 근접카메라.

### 후보 B — "PPE 미착용 게시" (조건부)
- PPE 착용검출 recall 67~76 는 쓸 만하나 **NO-Hardhat 56%(절반 놓침; ★2026-09-26 갱신 held-out 91장 64.1% [51.8, 74.7] — 여전히 우리 4클래스 중 최약)**이 약점 → "미착용 적발"보다 **"착용 독려 게시"** 수준의 낮은 확신 용도로만. 재학습 전엔 파일럿 부적합(추정).

- **rig_monitor**: 광역 CCTV 해상도 한계(B8). 근접 카메라 + 다중영상 검증 선행.
