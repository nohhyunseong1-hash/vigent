# 프로필 이미지 분석 메타 프롬프트

> 기존 관상 프롬프트를 대체하는 안전형 문서다.
> 목적은 얼굴로 성격·운명·궁합을 추론하는 것이 아니라, 프로필 이미지 품질을 관리하고 사용자가 직접 입력한 인상 정보를 결과 문맥에 자연스럽게 반영하는 것이다.

---

## 0. 정확도 원칙

이 모듈에서 정확도는 아래 세 가지다.

1. `품질 판정 정확도`
   - 정면 여부, 조명, 해상도, 단일 얼굴 여부를 안정적으로 판정한다.
2. `재현성`
   - 같은 이미지면 같은 품질 판정이 나온다.
3. `입력 충실도`
   - 사용자가 직접 선택한 인상 태그와 메모를 왜곡 없이 후속 해석 단계에 전달한다.

절대 원칙:
- 얼굴 이미지는 성격, 능력, 운명, 궁합, 위험도, 정신상태를 추론하는 데 사용하지 않는다.
- 얼굴 이미지는 오직 품질 검수, 크롭, 연출 메타데이터 생성에만 사용한다.
- 사람에 대한 해석은 사용자가 직접 입력한 정보와 사주 계산 결과를 중심으로 한다.

---

## 1. 입력 데이터 정의

### 1.1 이미지 입력

- 단일 프로필 사진 1장
- 선택 입력
  - 서브 사진 1~2장
  - 사용자가 원하는 분위기 키워드

### 1.2 사용자 입력

- 첫인상 태그
  - 예: 차분함, 단정함, 선명함, 부드러움, 밝음, 도시적, 따뜻함
- 외형 인상 메모
  - 예: 눈빛이 또렷해 보인다는 말을 자주 듣는다
- 자기소개
- 관심사

---

## 2. 이미지 품질 모듈

### 2.1 목적

- 프로필 카드에 적합한 사진인지 판정
- 품질 미달 시 재업로드 유도
- 원본 사진을 분석 결과의 성격 근거로 사용하지 않음

### 2.2 판정 항목

- 단일 얼굴 여부
- 정면도
- 조명 적정성
- 해상도
- 흔들림
- 얼굴 가림 여부
- 과도한 필터 여부

### 2.3 출력 예시

```json
{
  "accepted": true,
  "brightness_score": 0.82,
  "sharpness_score": 0.77,
  "face_count": 1,
  "frontal_score": 0.90,
  "feedback": ["프로필 품질 기준을 통과했습니다."]
}
```

### 2.4 금지 사항

- 눈, 코, 턱, 얼굴형으로 성격 추론 금지
- 얼굴형으로 궁합 점수 생성 금지
- 얼굴을 기반으로 우열, 매력 등급, 사회적 가치 판단 금지

---

## 3. 프로필 인상 보조 모듈

### 3.1 목적

- 사용자가 스스로 표현한 인상 정보를 구조화한다.
- 결과 카드에서 더 자연스러운 소개 문장과 관계 톤을 만든다.

### 3.2 구조화 규칙

- 첫인상 태그는 최대 5개
- 외형 인상 메모는 요약하지 말고 원문 우선 보존
- 사용자가 선택한 태그와 메모는 "자기 인식" 또는 "사회적 인상" 범주로만 사용

### 3.3 허용되는 해석 범위

- "사용자는 자신을 차분하고 단정한 인상으로 표현했다"
- "프로필 소개 톤은 부드럽고 안정적인 문장으로 맞춘다"

### 3.4 금지되는 해석 범위

- "이 얼굴은 원래 차갑고 계산적이다"
- "눈매가 올라가 있어서 지배욕이 강하다"
- "턱이 강해서 결혼운이 세다"

---

## 4. 궁합 시스템에서의 사용 범위

이미지 모듈 결과는 아래에만 쓴다.

- 프로필 완성도
- 카드 시각 연출
- 대화 아이스브레이커 문구
- 사용자가 입력한 첫인상 태그 기반 보조 설명

이미지 모듈 결과를 아래에 쓰면 안 된다.

- 사주 궁합 점수
- 성격 벡터
- 연애 성향 벡터
- 기질 분류

---

## 5. LLM 시스템 프롬프트

```text
너는 데이팅 앱의 프로필 요약과 사주 해석을 돕는 콘텐츠 생성기다.
다음 규칙을 반드시 지켜라.

1. 아래 <사주 데이터>, <사용자 입력>, <이미지 품질 결과>만 사용한다.
2. 얼굴 사진을 보고 성격, 운명, 능력, 궁합, 위험도, 민감 특성을 추론했다고 주장하지 않는다.
3. 사용자가 직접 입력한 첫인상 태그와 외형 메모는 "사회적 인상" 수준에서만 다룬다.
4. 명식·간지·오행·점수를 새로 계산하거나 변경하지 않는다.
5. 근거가 부족하면 단정하지 않는다.
6. 외모 비하, 우열 평가, 매력 등급화를 하지 않는다.
7. 결과는 전통 명리 기반 엔터테인먼트임이 드러나게 작성한다.

<사주 데이터>
{계산된 명식 및 구조화 지표}

<사용자 입력>
{첫인상 태그, 외형 인상 메모, 자기소개, 관심사}

<이미지 품질 결과>
{정면도, 조명, 해상도, 얼굴 수, 품질 피드백}

<요청>
이 사용자의 프로필 소개와 사주 중심 성향 요약을 작성하라.
```

## 6. 출력 구조

```json
{
  "image_quality": {
    "accepted": true,
    "feedback": ["프로필 품질 기준을 통과했습니다."]
  },
  "profile_impression": {
    "selected_tags": ["차분함", "단정함"],
    "appearance_note": "또렷한 눈빛이라는 말을 자주 듣는다"
  },
  "saju_summary": {
    "core_tone": "사주 계산 결과 기반 요약"
  },
  "dating_profile": {
    "intro_style": "안정적이고 신뢰감 있는 톤",
    "conversation_hooks": ["전시", "영화"]
  },
  "disclaimer": "얼굴 이미지는 품질 검수와 연출에만 사용되며, 해석은 사주와 사용자 입력을 중심으로 구성됩니다."
}
```

---

## 7. 품질 보증 체크리스트

- [ ] 동일 이미지 → 동일 품질 판정
- [ ] 얼굴 기반 성격 추론 문구 없음
- [ ] 외모 비하/우열 표현 없음
- [ ] 사주 계산 결과 변조 없음
- [ ] 사용자가 입력한 태그와 메모만 인상 정보에 반영

---

## 8. 윤리·면책

- 결과에 외모 평가, 우열, 매력 등급을 만들지 않는다.
- 얼굴 이미지는 민감정보로 취급한다.
- 원본 미저장 원칙을 우선한다.
- 삭제권과 보관기간 고지를 제공한다.
- 전통 명리 기반 엔터테인먼트임을 분명히 표기한다.
