# VIGENT USB — 사용법 (한 장)

이 USB 하나로 VIGENT 산업안전 감시 서버가 돌아갑니다. 대상 PC 에 파이썬이나 다른 프로그램을 설치하지 않습니다.
Windows 10/11(64비트) 노트북·데스크톱이면 됩니다. 그래픽카드가 없어도 됩니다(CPU 로 동작).

## 1. 시작 (더블클릭 한 번)

1. USB 를 꽂고 탐색기에서 USB 드라이브를 엽니다.
2. **`VIGENT_시작.bat`** 을 더블클릭합니다.
   - Windows 가 "Windows 의 PC 보호" 파란 창(SmartScreen)을 띄우면 **"추가 정보" → "실행"** 을 누릅니다. 처음 한 번만 묻습니다.
   - USB 를 꽂았을 때 자동으로 실행되는 기능(Autorun)은 Windows 가 보안상 막아 두었습니다. **더블클릭 한 번은 반드시 필요합니다.**
3. 검은 창이 뜨고 자가진단(파이썬·모델 파일·포트)을 거친 뒤 서버를 시작합니다. **15~60초** 뒤 브라우저가 자동으로 열립니다.
   - 주소는 `http://127.0.0.1:8010/home` 입니다. 브라우저가 안 열리면 이 주소를 직접 입력하세요.
   - 8010 포트를 다른 프로그램이 쓰고 있으면 자동으로 8011 로 바뀝니다(창에 표시됨).
4. **검은 창은 닫지 마세요.** 그 창이 서버입니다. 창을 닫으면 감시가 멈춥니다. 최소화만 하세요.

## 2. 카메라 등록

1. 브라우저 화면 상단의 **카메라/관제(허브)** 메뉴로 들어갑니다.
2. "카메라 추가" 에서 이름과 주소를 넣습니다. Tapo 등 RTSP 카메라 주소 예:
   `rtsp://아이디:비밀번호@카메라IP:554/stream1` (저화질 분석은 `stream2`)
3. 저장하면 몇 초 뒤 화면에 카메라가 나타납니다. 위험 구역은 화면에서 다각형으로 그려 저장합니다.
4. 텔레그램 알림을 쓰려면 브라우저의 알림 설정 화면에서 봇 토큰과 채팅 ID 를 넣습니다(USB 에는 저장돼 있지 않습니다).

## 3. 종료

- **`VIGENT_종료.bat`** 을 더블클릭합니다(이 USB 에서 실행된 것만 종료됩니다). 또는 검은 창을 닫습니다.
- USB 를 뽑기 전에 작업 표시줄의 **"하드웨어 안전하게 제거"** 를 꼭 쓰세요. 기록이 USB 안(`app\data`, `state\logs`)에 쓰이는 중이라 그냥 뽑으면 손상될 수 있습니다.

## 4. 알아 둘 것

- **기록은 전부 USB 안에 남습니다.** 증거 이미지·인식 기록은 `app\data`, 로그는 `state\logs` 입니다. 대상 PC 에는 아무것도 남지 않습니다. 반대로 말하면 USB 를 잃어버리면 그 기록도 함께 나갑니다. USB 는 잠긴 곳에 보관하세요.
- **속도**: CPU 로 돌기 때문에 카메라 1~2대 시연·점검 용도입니다. 여러 대 상시 감시는 고정 설치(서비스)로 합니다.
- **인터넷이 없어도 됩니다.** 모델 파일이 모두 USB 에 들어 있습니다. 텔레그램 알림만 인터넷이 필요합니다.
- 이 PC 에 NVIDIA 그래픽카드와 드라이버가 있고, 개발팀이 `python\wheels_cuda` 폴더를 넣어 줬다면 `VIGENT_시작.bat --gpu` 로 GPU 를 쓸 수 있습니다. 그 폴더가 없으면 이 옵션은 아무것도 하지 않습니다.

## 5. 문제가 생겼을 때

| 증상 | 조치 |
|---|---|
| 검은 창이 바로 닫힌다 | 닫히지 않게 만들어 두었습니다. 그래도 닫히면 USB 를 다시 꽂고, 창을 먼저 열어(`cmd`) USB 로 이동한 뒤 `VIGENT_시작.bat` 을 입력해 메시지를 읽습니다 |
| "DLL load failed" 라고 나온다 | 이 PC 에 "Microsoft Visual C++ 2015-2022 재배포 가능 패키지(x64)" 가 없는 것입니다. 마이크로소프트 사이트에서 `vc_redist.x64.exe` 를 설치하고 다시 실행합니다 |
| "필수 모델 파일이 없습니다" | USB 복사가 덜 된 것입니다. 개발팀에 USB 재복사를 요청하세요(인터넷에서 받지 않습니다) |
| 90초가 지나도 브라우저가 안 열린다 | 검은 창의 마지막 줄을 읽습니다. `state\logs\vigent.log` 를 개발팀에 보내면 됩니다 |
| 8010·8011 모두 사용 중 | `VIGENT_종료.bat` 을 먼저 실행한 뒤 다시 시작합니다 |
| 카메라가 "입력 끊김" | 카메라 주소·비밀번호·같은 네트워크인지 확인. 노트북은 유선, 카메라는 카메라 전용 공유기가 안정적입니다 |
| 창에 한글이 깨져 보인다 | 동작에는 문제 없습니다. 창 제목줄 우클릭 → 속성 → 글꼴을 "맑은 고딕" 계열로 바꾸면 보입니다 |

개발팀 연락 시 함께 보낼 것: `state\logs\vigent.log`, `state\logs\selftest_import.err`(있으면), 검은 창의 화면 캡처.
