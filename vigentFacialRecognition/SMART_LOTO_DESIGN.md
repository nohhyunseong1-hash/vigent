# Smart LOTO 설계도 — 얼굴·라이브니스·MFA 기반 전자 잠금/표시

## 0. 안전 경계 (가장 먼저 — 반드시 준수)
**LOTO(Lock-Out/Tag-Out)** = 정비 중 기계가 갑자기 가동돼 작업자가 다치지 않도록 에너지원을
차단·잠그고 표지하는 절차(산업안전보건법, OSHA 29 CFR 1910.147, KOSHA).

- 법정 1차 보호 = **작업자 본인이 직접 채우는 물리적 패드락**(본인만 열쇠 보유). 이건 대체 불가.
- **Smart LOTO가 추가하는 것(보조 계층)**: ① 누가 잠갔는지 **신원 인증**(얼굴+라이브니스+MFA),
  ② **위·변조 불가 감사기록**(누가·언제·증거사진), ③ **전자 인터록 신호**(서보/릴레이로 기동 차단),
  ④ 그룹 LOTO **상태 가시화**.
- ⚠ 본 프로토타입의 서보는 **표시·보조 인터록**이며, 인증 안전회로(안전PLC·정격 차단기)나
  작업자 패드락을 대체한다고 표기/사용하지 말 것. **페일세이프 기본 = 잠금(기계 비활성)**.

---

## 1. 개념 매핑 (기존 자산 → Smart LOTO)
```
누구인가   → 얼굴 인식(SFace)          : person_id 확정
진짜 사람? → 라이브니스(고개돌림+맥박)  : 사진/영상 위조 차단
다요소     → MFA(카드/PIN/홍채)         : 고위험 구역 2~3요소
기록       → privacy.audit             : 잠금/해제 전 과정 감사
액추에이터 → Arduino + 서보             : LOCKED(기계 비활성) / UNLOCKED(기동 허용)
```

## 2. 시스템 아키텍처
```
 ┌─────────────────────────── PC (VIGENT) ───────────────────────────┐
 │  웹캠 ──► 얼굴인식 + 라이브니스 + MFA(Authenticator)               │
 │                     │ person_id 확정                              │
 │                     ▼                                             │
 │  smartloto.LotoStation  ── 그룹 LOTO 상태머신 + 잠금대장          │
 │                     │ set_locked(True/False)                      │
 │                     ▼                                             │
 │  loto_serial.LotoController ──(USB 시리얼)──►  Arduino            │
 │            (장비 없으면 시뮬레이션 폴백)                          │
 └───────────────────────────────────────────────────────────────────┘
                                  │ "LOCK"/"UNLOCK"/"PING"
                                  ▼
 ┌─────────────────────────── Arduino UNO ───────────────────────────┐
 │  서보(D9) = 잠금 볼트   RED(D7)=잠김  GREEN(D8)=해제  BUZZER(D6)   │
 │  부팅 시 = 잠금(페일세이프)                                        │
 └───────────────────────────────────────────────────────────────────┘
```

## 3. 부품 목록 (BOM — 프로토타입)
| 부품 | 사양 | 비고 |
|---|---|---|
| Arduino UNO/Nano | ATmega328 | USB로 PC 연결 |
| 서보모터 | SG90(소형) 또는 MG996R(토크↑) | 잠금 볼트 구동 |
| LED 2개 | 빨강/초록 + 220Ω 저항 | 상태 표시 |
| 부저 | 액티브 5V | 경보(선택) |
| 외부 5V 전원 | MG996R 사용 시 필수 | 서보 전류스파이크 대비, **공통 GND** |
| 점퍼/브레드보드 | — | — |

> SG90은 아두이노 5V로 프로토타입 가능. MG996R 등 토크 큰 서보는 **별도 5V 전원 + 공통 그라운드** 필수(아두이노 5V로 직접 구동 금지).

## 4. 배선도 (핀 맵)
```
Arduino UNO
  D9  ──────────────► 서보 신호(주황)
  5V  ──────────────► 서보 VCC(빨강)      ※ MG996R는 외부5V+로
  GND ──────────────► 서보 GND(갈색) ─┬─ 외부전원 GND(공통)
  D7  ──[220Ω]──►|── RED LED  ── GND     (잠김=ON)
  D8  ──[220Ω]──►|── GREEN LED── GND     (해제=ON)
  D6  ──────────────► 부저(+),  부저(−)── GND   (선택)
  USB ──────────────► PC (시리얼 9600)
```

## 5. LOTO 상태머신 (그룹 LOTO)
```
        apply_lock(작업자)              apply_lock(추가 작업자)
            │                                  │
            ▼                                  ▼
   ┌──────────────┐   마지막 잠금 해제   ┌──────────────┐
   │  LOCKED_OUT  │ ────────────────►   │  SAFE_IDLE   │
   │ (1+ 잠금)    │ ◄────────────────   │ (잠금 0)     │
   │ 기계 비활성  │   apply_lock        │ 기계 비활성  │
   └──────────────┘                     └──────┬───────┘
        ▲  서보=LOCKED, RED                     │ energize(관리자/작업자)
        │                                       ▼
        │  apply_lock 즉시 잠금          ┌──────────────┐
        └────────────────────────────── │  ENERGIZED   │
                                         │ 기계 기동 허용│ 서보=UNLOCKED, GREEN
                                         └──────────────┘
```
규칙:
- **잠금이 1개라도 있으면 기계 비활성**(서보 LOCKED). 모두 풀려야 기동 가능.
- **본인 잠금은 본인만 해제**(다른 사람 잠금 해제 금지 — LOTO 핵심). 관리자 강제해제는 별도 감사.
- `energize`는 잠금 0일 때 **명시적 동작**으로만(자동 기동 금지).
- 페일세이프: 불확실/부팅/시리얼 단절 → **LOCKED**.

## 6. 동작 시퀀스
**① 잠금(작업 시작 전)**
```
작업자 → 웹캠 인증(얼굴+라이브니스, 고분진이면 +카드/PIN) → person_id
 → LotoStation.apply_lock(person_id, 증거사진)
 → 상태 LOCKED_OUT, 서보 LOCKED, RED, 감사기록
```
**② 해제(작업 종료)**
```
작업자 → 재인증(본인 확인) → remove_lock(person_id)
 → 남은 잠금 있으면 그대로 LOCKED, 없으면 SAFE_IDLE
```
**③ 기동**
```
관리자/작업자 → 인증 → energize()  (잠금 0일 때만)
 → 서보 UNLOCKED, GREEN
```

## 7. 시리얼 프로토콜 (PC ↔ Arduino, 9600 8N1, 줄 단위)
| 방향 | 메시지 | 의미 |
|---|---|---|
| PC→ | `LOCK` | 잠금(기계 비활성) |
| PC→ | `UNLOCK` | 해제(기동 허용) |
| PC→ | `PING` | 생존 확인 |
| →PC | `STATE:LOCKED` / `STATE:UNLOCKED` | 현재 상태 |
| →PC | `PONG` | 응답 |

## 8. 구현 파일
- `arduino/smart_loto.ino` — 아두이노 펌웨어(서보·LED·시리얼, 부팅 시 잠금).
- `loto_serial.py` — pyserial 컨트롤러. **장비/라이브러리 없으면 시뮬레이션 폴백**.
- `smartloto.py` — 그룹 LOTO 상태머신 + 잠금대장 + 감사.
- `tests/test_smartloto.py` — 상태머신 검증(가짜 컨트롤러).
- (다음) `/loto/*` 엔드포인트 + 통합 데모 탭.

## 9. 빌드 순서
1. 아두이노에 `smart_loto.ino` 업로드 → 시리얼 모니터로 `LOCK`/`UNLOCK` 수동 시험.
2. `pip install pyserial` → `loto_serial.py`로 PC에서 서보 제어(포트 `VIGENT_LOTO_PORT`).
3. `smartloto.py` 상태머신 + 인증(MFA/라이브니스) 연결.
4. 웹 데모 탭(잠금/해제/기동, 그룹 잠금 현황) — 다음 단계.

## 10. 실서비스로 갈 때(프로토타입 → 현장)
- 서보 → **솔레노이드 볼트/전기 정비락 + 정격 릴레이/안전PLC**(인증 등급).
- 기계 제어회로(저압 24V) 인터록, 메인 동력 직접 제어 금지.
- 작업자 **물리 패드락 병행 유지**(법정). Smart LOTO는 신원·기록·가시화 보조.
- 비상정지·존재감지(IEC 62046)는 별도 인증 하드웨어.
