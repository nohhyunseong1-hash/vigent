## 2. 문제 정의

### 2-1. 중량물 인양(줄걸이) 사고의 구조

크레인 인양 작업의 사고는 **작업 절차의 특정 지점**에서 반복적으로 발생한다.

- **결속(줄걸이) 단계**: 작업자가 하물에 밀착해 슬링·후크를 건다 — **근접이 정상 절차**인 구간.
- **인양 개시 단계**: 하물이 뜨기 시작한다 — 이때 **작업자가 아직 반경 안에 있으면** 협착·끼임·전도로 이어진다.
- **본 인양 단계**: 하물이 이동한다 — **하부 진입자**가 낙하물 위험에 노출된다.

즉 **"작업자가 하물 근처에 있다"는 사실 자체는 위험 신호가 아니다.** 위험은 **절차의 어느 단계에서 근접하는가**에 달려 있다. 이 구분을 못 하면 경보가 남발되고, 남발된 경보는 결국 무시된다(경보 피로).

## 3. 솔루션 — 3층 구조

### L1. 실시간 감지 계층
CCTV 영상에서 **작업자·보호구(안전모/조끼)·화재·연기**를 실시간 검출하고, 지정한 위험구역 진입을 판정한다.
- 전 모델 **permissive 라이선스**(RF-DETR/Apache-2.0)로 이관 완료 → **배포 경로 강카피레프트(AGPL) 0**.
- **모델 불가지론 설계**: 모델 경로를 설정으로 주입 → 현장 데이터 재학습 시 코드 변경 없이 교체.

### L2. 문서 자동화 계층
감지 결과를 **법령 근거가 달린 위험성평가서(체크리스트법)**로 자동 초안화한다.
- 근거: **산업안전보건법 제36조 + 고용노동부고시 제2024-76호 제7조**(체크리스트법).
- **법령 화이트리스트 게이트**: 검수된 조문(23개) 밖의 조문은 AI가 인용할 수 없다 → **"안전관리자 확인 필요"로 치환**.
- **비전 사각지대 표면화**: 카메라로 못 보는 항목(신호수 배치, 안전검사 등)을 **"수동확인 필요"로 명시** — 조용히 누락시키지 않는다.
- 모든 산출물은 **"안전관리자 검토용 초안"**으로 표기(자동 승인 없음).

### RIG. 줄걸이 특화 계층 *(특허 출원 예정 — 개요만 기재)*
인양 작업의 **절차 단계를 인식**해, **정상 절차상의 근접**과 **위험한 이탈 상황**을 구분한다.
- **효과 ①**: 결속 단계의 정상 근접에는 경보하지 않는다 → **경보 피로 방지**.
- **효과 ②**: 절차를 벗어난 위험 상황에서만 경보한다 → **경보의 신뢰도 확보**.
- **효과 ③**: 출력을 **상태 인지(저강도)와 경보(고강도) 2단계**로 분리 → 관리자가 "지금 무슨 작업 중인지"까지 파악.
- 세부 전이 조건·임계값 등 메커니즘은 **특허 출원 전이므로 본 문서에 기재하지 않는다.**

| 한계 | 실측 근거 | 대응 |
|---|---|---|

## 5. 추진 계획 (본체)

### 5-0. 단기 필수 — 파일럿 전 "제품 배선 마감"

> 자체 감사(2026-07) 결과, **검증은 끝났으나 제품 경로에 배선이 안 된 기능 3건**을 확인했다. 파일럿 투입 전 반드시 마감한다. (기술 리스크가 아니라 **연결 작업**이다.)

| # | 항목 | 현재 | 마감 후 |
|---|---|---|---|
| **G1** | **L1 → 체크리스트 자동 연동** | 감지 결과를 사람이 수동 입력해야 문서가 생성됨 | 감지 이벤트가 **자동으로** 해당 점검항목을 부적정(X)으로 표기 |
| **G2** | **점검항목 전체 나열(item_pool) 제품 반영** | 제품 API는 **감지된 항목만** 출력 | 검증 완료된 **전 항목 나열 + 미감지 항목 "수동확인 필요"** 를 제품에 반영 |
| **G3** | **법령 환각 차단을 문서 생성 경로에도 적용** | AI 자유생성 경로는 차단되나, 규칙 경로는 **감사(로그)만** → 미검수 조문이 문서에 잔존 | 문서 생성 경로에도 차단 정책 적용 여부 결정·반영 |

## 10. 리스크와 대응

| 리스크 | 실체 | 대응 |
|---|---|---|
| **현장 도메인 갭** | 공개 데이터셋 성능이 현장에서 재현된다는 보장 없음. **실제 CCTV에서 작업자 26~64px 실측** | ① 파일럿 = **현장 최초 측정** ② 현장 데이터 파인튜닝(S4) ③ **근접 카메라 2대 구성**으로 물리적 해결 |
| **비전의 원리적 한계** | 카메라로 못 보는 항목 존재(밀폐공간·프레스는 자동판정 0/7 실측) | **"수동확인 필요"로 표면화** — 못 보는 것을 못 본다고 말하는 것이 안전상 정답 |
| **경보 피로** | 오경보가 쌓이면 진짜 경보도 무시됨 | RIG의 **절차 인식**으로 정상 근접 제외 · **2단계 출력**(인지/경보) 분리 · 신뢰 못 할 검출기는 **명시적으로 끔**(지게차) |
| **1인 개발 리스크** | 속도·연속성 | 검증 자동화 체계(테스트·벤치·골든셋 채점) + 모든 결정을 **문서·커밋으로 추적 가능**하게 유지 |
| **인증 일정 불확실** | KISA 인증 소요기간 미확인 | `[기입]` — 조기 착수, 인증 전에는 **"보조·감시 계층"**으로만 공급 |
| **법적 책임 경계** | AI 오탐/미탐 | **인증 안전장치를 대체하지 않는 보조 계층**임을 계약·UI·문서에 명시. 모든 문서는 **"안전관리자 검토용 초안"** |
| **개인정보** | 근로자 영상 | **원본 영상 현장 외 반출 금지**(코드로 강제 — 외부 전송 기본 차단), 고지·노사협의, 얼굴 블러 |
