## 준비 (터미널에서 1회)

새 폴더를 만들고, 되돌리기용 git을 켜고, Claude Code를 실행합니다.

```bash
mkdir ~/Desktop/VIGENT
cd ~/Desktop/VIGENT
git init
```

그다음 이 폴더 안에 **`CLAUDE.md`** 와 **`VIGENT_META_PROMPT.md`** 두 파일을 넣고, 같은 위치에서 `claude` 를 실행하세요.

> 💡 `CLAUDE.md`는 Claude Code가 매번 자동으로 읽으므로, 아래 지시문에서 매번 규칙을 다시 설명할 필요가 없습니다.

## 막혔을 때 쓰는 만능 문장

- 에러가 났을 때: `방금 에러가 났어. 에러 메시지 전체를 보여주고, 원인과 해결책을 초보자도 알게 한국어로 설명한 뒤 고쳐줘.`
- 너무 많이 바꿨을 때: `방금 변경이 마음에 안 들어. 직전 커밋 상태로 되돌려줘.`
- 이해가 안 될 때: `방금 만든 게 무슨 역할인지, 내가 뭘 확인하면 되는지 3줄로 설명해줘.`
- 설치하라고 할 때: `설치하기 전에, 뭘 왜 설치하는지와 위험은 없는지 먼저 알려줘.`
