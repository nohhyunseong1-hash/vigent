# 골든셋 — 위험성평가 강사 정답 세트 (safety)

## 목적
에이전트(특히 Scribe/Analyst) 출력을 **사람 전문가(강사) 정답**과 대조해
정확도를 측정하기 위한 기준 데이터. 정답이 있어야 채점(t_hall 환각·t_down 저하)이 가능하다.

## 절대 원칙
- **정답은 AI가 작성하지 않는다.** Claude Code는 (a) 시나리오 뼈대, (b) 빈칸 템플릿,
  (c) "현재 제품 출력(Scribe)"까지만 제공한다. **값 확정은 노현성(강사)** 이 한다.
- 정답의 근거(법령)는 화이트리스트(`data/legal/statutes.yaml`) 내에서 인용한다.
  화이트리스트 밖 조문이 필요하면 "추가 검수 대기열"에 올린다(지금 지어내지 않음).

## 채점 지표(정답 확정 후 계산)
- **t_hall(환각)**: 정답에 없는 위험요인/법령을 제품이 만들어냈는가(거짓양성).
- **t_down(저하)**: 정답에 있는 위험요인을 제품이 놓쳤는가(거짓음성).
- 빈도·강도·등급 일치율, 감소대책 위계 적정성.

## 스케일(제품과 동일하게)
- **빈도(가능성) 1~3**, **강도(중대성) 1~3**, 위험성 = 빈도 × 강도(1~9), 등급: 상(6~9)/중(3~4)/하(1~2).
- **감소대책 위계**(고시 제12조 순서): ① 제거·대체 → ② 공학적 → ③ 관리적 → ④ 개인보호구.

## 진행 상태
| # | 시나리오 | 정답 상태 |
|---|---|---|
| 01 | 크레인 양중(작업반경·PPE·낙하물) | ✅ 강사 확정(노현성, 2026-07-12) · 첫 채점 완료 |
| 02~30 | (예정) | ⬜ 미작성 |

**채점 사이클(item_01)**:
- 1차 69점 → 감소대책 위계 미구현(0/3) 진단.
- 2차 **89점**(+20) — Scribe에 고시12조 위계 분류 구현(설비>인적). 위계 3/3, **회귀 없음**(빈도/강도/등급/법령/환각 불변).
- 남은 개선 백로그: 빈도 과소평가 1건, 크레인 특화 제40·146조 미인용(×2), 제15조 환각.

파일: `item_NN_*.md`(정답 서식), `item_NN_*_scribe.json`(현재 제품 출력 덤프, 대조용).
