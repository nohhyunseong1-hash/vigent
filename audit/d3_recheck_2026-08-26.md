## 0. 연결 — ★두 가지 함정을 만났다

**함정 ①: 같은 id 로 재등록하면 스트림이 안 바뀐다**

브라우저로 C200 을 등록했는데 **화면에 공사현장 영상(소크용 파일)이 계속 나왔다.**
등록부에는 RTSP 주소가 반영됐지만 **워커는 옛 파일 소스로 계속 돌고 있었다.**

```
등록부 : rtsp://***@192.168.0.4:554/stream1     ← 새 주소
워커   : C:\...\runs\rfdetr\accident\...mp4      ← 옛 소스
```

`WorkerManager.start()` 는 이미 실행 중인 워커를 만나면 `{"ok": False, "error": "이미 실행 중"}`
을 돌려주고 **그냥 둔다**. 브라우저에서는 성공처럼 보인다.
→ `disable → enable` 로 재부착하니 RTSP 로 전환됐다.
★**스냅샷을 눈으로 보지 않았다면 공사현장 영상을 C200 이라 착각한 채 진행했을 것이다.**
**현장 영향**: NVR 채널 주소를 고치려고 재등록해도 화면이 그대로다 → "주소가 또 틀렸나"
하며 헤맨다. → 별도 결함으로 등재.

**함정 ②: 카메라 이름이 `d` 한 글자로 저장됐다**

브라우저 등록 시 이름 칸에 `d` 만 들어갔다(입력 실수). 결과: 텔레그램이
`[d] 위험구역 내 작업자 감지` 로 도착한다. 기능엔 영향 없으나 **여러 카메라 중 어느 것인지
구분할 수 없다.** 현장에서는 등록 직후 `/cameras` 로 이름을 눈으로 확인할 것.

## 2. ★지연 진단 — "굼떠 보이는 것"과 "감지가 늦는 것"을 갈랐다

### 결론: **위험 감지는 늦지 않는다.** 굼떠 보이는 것은 화면 갱신 주기다.

| 지표 | 실측(단독, 파일 카메라 제거 후) | 뜻 |
|---|---|---|
| `frame_age` | **p50 0.3s** (max 0.6) | 프레임이 밀리지 않는다 |
| `detect_age` | **p50 0.3s** (max 0.6) | 검출이 현재를 본다 |
| `dropped_frames` / `reconnects` | **0 / 0** | 유실·끊김 없음 |
| 스냅샷 API 응답 | **498~767ms** | ← **눈에 굼떠 보이는 원인** |

카메라 OSD 시각과 노트북 시각 직접 대조: `18:47:54` vs `18:47:56` (**2초**) — 이 2초에는
스냅샷 요청 0.655초와 카메라 자체 시계 오차가 섞여 있다. 서버 지표(`frame_age 0.3s`)가
실제 프레임 지연이다.

**즉 "과거를 보고 판단하는" 상태가 아니다.** 사람이 구역에 들어오면 0.3초 안에 그 프레임이
판정에 들어간다. 화면이 뚝뚝 끊겨 보이는 것은 **표시 경로(스냅샷 폴링)** 이고 판정과 무관하다.

### 개발 PC 대비

| 지표 | 개발 PC(유선) | 노트북(무선 2홉) | 해석 |
|---|---|---|---|
| `read_ms` | 134.8 | **128.5** | **거의 동일 — 네트워크가 병목이 아니다** |
| `infer_ms` | 184.3 | **244.0** | +60ms — GPU 차이(RTX 5070 Ti vs GTX 1650 Ti) |

★이 값은 **무선 2홉** 조건이다. **현장은 유선 계획**이라 `read_ms` 가 나빠질 이유는 없으나,
**NVR 경유·H.265** 이면 달라질 수 있다(별도 미검증).

## 3. ★0-J 재현 — [D1-C] 사람 단위 판정이 실카메라에서 동작

**무인 오탐 기준선**(40초): person 오탐 **100%(14/14)**, conf 0.358~0.662.
고정 위치 2곳 — `(0.92, 0.95)` 14회, `(0.66, 1.00)` 9회. **그 자리를 피해** 구역을 왼쪽

**결과**


**★D1-C 사람 단위 경로 확인**: person 검출에 **트랙 id 가 유효**하게 붙는다(`tid=10001333`,
4회 연속 동일). `_derive` 가 폴백(카메라 단위)이 아니라 **사람 단위 분기**를 타므로

> 한 사람만으로는 "B 가 A 에 가려지지 않는다"를 직접 재현할 수 없었다(두 번째 사람 필요).
